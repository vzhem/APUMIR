# APU v11.74.99 — пересланная гифка снова карточкой

## Что изменилось (продолжение раунда 203)

Владелец (скрин лички с Server67): переслал гифку из группы в личные
сообщения — «а там какой то код»; шапку отметил кликабельной.

### Причина

Проверка «это ссылка на гифку» (раунд 128) смотрела в НАЧАЛО
message.content. У пересланного там служебные строки APUFWD1 (маркер)
и шапка-источник — гифка не узнавалась, и пузырь печатал
«APUGIFREF1|<sha256>» как текст.

### Фикс

- Личка (ChatDetailScreen): гифку узнаём в ForwardMarker.stripHeader
  тела; GifRefCard получает очищенный реф.
- Группы/каналы (GroupChatScreen.MessageBubble): та же проверка по
  bodyText (он уже без маркера и шапки); GifRefCard - bodyText.
- Превью в «Действиях с сообщением» - без служебных строк (раньше
  показывало «APUFWD1|…»).
- «В избранное» (личка и группы) сохраняет тело без маркера/шапки -
  сохранённая гифка снова играет карточкой.
