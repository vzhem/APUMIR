# APU v11.74.11 — сервер в настройках без лишних деталей

## Главное

Строка сервера в «Настройки → Сервер» больше не показывает технический
адрес — только нейтральное имя **«Наш сервер»** и его состояние
(доступен, время отклика). Приложение продолжает работать с тем же
сервером, изменилась только подпись на экране (просьба владельца).

## Прочее

Без изменений сервера, шифрования и доставки.
