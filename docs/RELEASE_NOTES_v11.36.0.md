APU v11.36.0

Обновление про связь: абоненты должны находить друг друга заметно лучше, особенно через интернет.

- Телефон теперь запоминает интернет-адрес собеседника из его объявления о присутствии — раньше этот адрес отбрасывался, и связь через интернет держалась только на очереди сообщений.
- Собственный адрес больше не остаётся пустым: он обновляется, а не определяется один раз при запуске, когда сеть ещё не готова.
- Внешний адрес переопределяется при смене сети — после перехода Wi-Fi ↔ мобильный интернет телефон снова становится доступен без перезапуска приложения.
- Кнопка «Собрать данные об абонентах» в настройках теперь действительно рассылает объявление о себе.

Известное ограничение: голосовые звонки между разными сетями пока нестабильны — это отдельная задача.
