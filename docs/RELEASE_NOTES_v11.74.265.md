# APU v11.74.265 — Статус файлов в групповом чате на английском

Строки состояния файла в групповом чате («Получено», «Приём», «Ожидание», «Ошибка приёма») теперь выводятся на выбранном языке. Логика показа статуса переведена на коды состояний, поэтому она не зависит от языка.
