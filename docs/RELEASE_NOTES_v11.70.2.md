# APU v11.70.2

Посты в каналах стали полноценными.

- До шести фотографий в одном посте: в ленте они листаются галереей со счётчиком. Каждое фото уходит отдельными небольшими пакетами, поэтому посты с фото теперь доходят и через интернет, а не только по одной Wi-Fi-сети.
- Пост можно исправить: карандаш в углу карточки виден автору поста и владельцу канала. Заголовок поста обновляется вместе с текстом, фотографии остаются прежними.
- Кто подписался на канал позже, видит последние 20 постов вместе с фотографиями и может оставлять комментарии под ними. Посты досылает владелец канала при подписке и при открытии канала.
- После публикации поста приложение больше не пишет «не отвечает»: рассылка ушла с главного потока.
- «Назад» из поста, открытого по ссылке, ведёт к списку постов канала, а не к окну входа по ссылке. Подписи нижней панели больше не обрезаются на узких экранах.

Обновление получают все: окно с предложением обновиться появится при запуске.
