# APU v11.74.206 — Повторная отправка недоставленных сообщений и файлов

Если собеседник был офлайн или срок передачи истёк, отправку теперь можно повторить прямо из переписки.

- Для недоставленных сообщений и файлов доступно действие «Повторить отправку».
- Повтор сообщения использует прежний идентификатор, заново ставит отправку в очередь и начинает новый срок хранения — до 7 дней.
- При повторе тяжёлого файла передача готовится заново; срок хранения начинается заново и составляет до 24 часов.
- Для повтора файла нужно снова выбрать его в системном окне. Приложение не сохраняет URI или путь к исходнику.
