# APU v11.74.1

Исправлена установка обновления, скачанного по сети от соседей.

- Кнопка «Обновить до vX» в разделе «Настройки → Обновления» теперь открывает установщик (раньше она молча ничего не делала).
- Если установка всё же не началась, приложение честно скажет почему — например, если не разрешена установка из неизвестных источников.
- Всё остальное — как в v11.74.0.

Обновление получают все: окно с предложением обновиться появится при запуске.
