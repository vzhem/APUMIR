# Значки фирменных обоев чата (v11.28+, темы день/ночь)

Обои `chat_wallpaper_dark.jpg` / `chat_wallpaper_light.jpg` в
`android-app/app/src/main/res/drawable-nodpi/` составлены из 109 оригинальных
контурных значков на тему децентрализованного мессенджера.
Генератор: `tools/wallpaper/wallgen.py`, превью набора:
`tools/wallpaper/preview_icons.png`. Ни один значок не заимствован из
референсов - только своя тематика: сервера, топологии, соединения, письма,
группы, устройства, приватность, блоки.
