# Раздел «Настройка IPv6» и рекомендации по покупке IPv6

В разделе **«Настройки → Сеть»** расположены две соседние карточки:

1. **«Настройка IPv6»** — ввод реквизитов купленного IPv6-прокси (или собственного
   сервера) с мгновенным применением к движку и сетевым запросам приложения без
   перезапуска и без ограничений по рангу.
2. **«Где приобрести IPv6»** — рекомендация проверенного магазина
   `https://ru.shopproxy.net/buy-proxy/ipv6/` с кнопками открытия сайта и
   копирования ссылки, а также явным пояснением, что пользователь может выбрать
   любой другой сервис, магазин прокси или свой собственный сервер.

---

## Поддерживаемые форматы ввода

Пользователь может заполнить отдельные поля (**Протокол**: `SOCKS5` или `HTTP / HTTPS`,
**IP-адрес или сервер**, **Порт**, **Логин**, **Пароль**) либо нажать
**«Вставить одной строкой из буфера»**:

- `ip:port:login:password` (стандартная выгрузка `shopproxy.net` и большинства магазинов);
- `[2a00:1fa0::1]:port:login:password` и `[2a00:1fa0::1]:port`;
- `login:password@host:port` и `login:password@[2a00:1fa0::1]:port`;
- `socks5://login:password@host:port`, `http://login:password@host:port`;
- `host:port` (для прокси с привязкой по IP без пароля);
- многострочная карточка из личного кабинета (`IP:`, `Порт:`, `Логин:`, `Пароль:`).

## Как именно приложение работает через введённые настройки

1. **MQTT-сессии Rust-ядра (`rust-core`):**
   - Для `SOCKS5` реквизиты передаются напрямую в `RustBridge.setMqttSocks5Proxy`
     (`rust-core/src/network/socks5.rs` поддерживает домены `ATYP=0x03`, IPv4 `ATYP=0x01`,
     IPv6 `ATYP=0x04` и скобки `[...]`).
   - Для `HTTP / HTTPS` поднимается локальный петлевой мост `127.0.0.1:<порт>`
     (`Ipv6HttpConnectBridge` в `Ipv6ProxyRuntime.kt`), переводящий запросы `SOCKS5`
     движка в туннель `HTTP CONNECT` с заголовком `Proxy-Authorization: Basic`.
   - При смене или отключении прокси `lib.rs` вызывает
     `mqtt_transport::note_broker_settings_changed()`, а проба брокеров
     (`multi_broker::probe_broker`) идёт через прокси — текущая сессия
     переподключается сразу, без потери очереди сообщений.
2. **HTTP/HTTPS-запросы приложения (`Ipv6ProxyRuntime`):**
   - Глобальные `ProxySelector` и `Authenticator` направляют внешние запросы
     (`CloudflareRelay`, реестр, облачная копия, обновления) через заданный прокси,
     оставляя локальные и домашние адреса (`127.0.0.1`, `192.168.*`, `10.*`,
     `172.16–31.*`, `fe80::*`, `.local`) прямыми.
   - Учётные данные отдаются только при совпадении хоста и порта прокси.
3. **Приоритет и хранение (`Ipv6NetworkSettings.kt`):**
   - Применяется в `MessengerApplication.onCreate()` до старта службы и при смене
     сети в `NetworkMonitor`.
   - Пока пользовательский IPv6-прокси включён, `ProxyAutopilot` не перезаписывает
     и не сбрасывает его пулом бесплатных прокси.
   - Пароль шифруется ключом Android Keystore (`AES/GCM/NoPadding`).
   - Сброс раздела «Сеть» (`SettingsResetStore.resetNetwork`) выключает маршрутизацию
     через прокси, сохраняя введённые реквизиты, чтобы покупные данные не пропали.
