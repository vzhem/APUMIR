- Правка отправленного сообщения теперь доезжает до всех: раньше телефон, лежавший без сети, навсегда оставался со старым текстом.
- Если вы отредактировали сообщение, а собеседник его ещё не получил, он попросит текст сам — правка не потеряется.
- «Удалить и модерация…» больше не роняет приложение — ни в личке, ни в группе, ни в канале.
- Подсказки адреса больше не занимают место, отведённое переписке: очередь перестала копить служебные записи неделями.
- В отчёте «последнее падение» теперь видна дата — старый след от давно исправленной ошибки больше не выглядит свежим.
- Сайт всегда отдаёт самый свежий выпуск: выкладка больше не спотыкается, если GitHub задерживает метку Latest.
- Выкладка на сайт больше не может «позеленеть», не обновив страницу: сбой публикации теперь виден и валит сборку, а не прячется.
