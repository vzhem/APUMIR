# APU v11.74.244 — Сообщения каналов на английском

Сообщения экрана канала, которые формирует модель канала, теперь выводятся на выбранном языке: публикация и редактирование постов, сохранение в избранное, пересылка и ошибки файлов.

- Ошибки публикации, создания и редактирования поста.
- Сообщения о файлах: не приложен, не запрошен, не сохранён, не получен полностью.
- Статусы избранного и пункты «Поделиться» для поста и файла.

Пока на русском: сообщение о нескольких картинках, которые не удалось прикрепить (количество выводится из кода).
