# Быстрее запасной путь через помощников

- Если телефон-помощник временно не может принять пакет, запасной путь запускается сразу.
- Отказавший помощник ненадолго получает меньший приоритет, но остаётся запасным вариантом.
- Исправлена редкая аварийная остановка при диагностике русского текста и эмодзи.

Старые версии продолжают работать по прежней схеме. Доступность связи зависит от сети.
