## Что изменилось

Владелец (скрин «Сообществ»): «в поиске сообщества тоже отображаются
системные ссылки вместо гифок; проверь, может ещё есть места».

Дочищены оставшиеся места (util/ChatPreviews.human):
- GroupsScreen «Мои группы» - строка «N участн. • APUGIFREF1|...»
  (со скрина);
- GroupChatScreen закреп темы - гифка-ссылка в закрепе светилась сырой;
- CoreServerService текст уведомлений - стикер-конверты шли сырыми.

Больше сырых мест нет: пройден весь ui/ (ContactCard, ChatListScreen,
GroupsScreen, список тем, закреп) + уведомления + запись (preview(),
updateLastMessage).

### Конверты роя молчат (решение владельца, опция «спрячь»)

ChatPreviews.isServiceEnvelope: APUSTK1| (каталог стикеров) и APUGIF1|
(провод гифок - миниатюры/порции) - служебные данные, НЕ сообщения:
- не оглашаются уведомлениями (фильтр recentIncoming);
- не накручивают unreadCount (saveIncomingMessage, р150-логика сохранена
  для настоящих сообщений).
APUGIFREF1 - настоящие сообщения-карточки: уведомляются и считаются
как раньше.
