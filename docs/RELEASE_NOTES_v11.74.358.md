# APU v11.74.358 — автоматический контроль накопления мусора

Приложение само обслуживает служебное хранилище и временные файлы, без ручной очистки абонентом.

- Периодическая очистка просроченных данных пересылки и безопасное освобождение свободных страниц базы.
- Короткоживущие сигналы и служебные повторы больше не занимают хранилище как обычная переписка; ограничен приём новых чужих копий.
- Фоновая уборка старых временных копий, остатков передач и собственных устаревших APK.
- История, полученные документы, голосовые сообщения и ключи действующих данных не очищаются по возрасту.
- Дополнительные показатели очистки и хранения в «Логах».
- Многострочный редактор историй с переносами строк и предпросмотром оформления.

**Известное ограничение:** очистка выполняется постепенно; Android может откладывать фоновые задачи. Ошибки недоступных ключей не исправляются этой версией; проверка на физических телефонах ещё не проведена.
