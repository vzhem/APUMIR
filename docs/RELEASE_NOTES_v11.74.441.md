# v11.74.441

**Безопасная очистка старых адресов одного телефона**

- При первом запуске новой версии приложение проверяет известные сетевые адреса и автоматически удаляет старые `pk_`, которые были созданы на этом же телефоне и больше не являются текущим профилем.
- Проверка выполняется только при наличии локального доказательства через Android Keystore. Чужие адреса с таким же `@ником` автоматически не удаляются.
- Связанные старые контакты, чаты, закреплённые ключи и маршруты очищаются; переписка переносится на текущий живой адрес, если это безопасно.
- Локальные tombstone-маркеры не позволяют старому gossip-пакету вернуть удалённый адрес после выхода из аккаунта и повторного входа.
- Поиск по `@нику` группирует одинаковые регистрации, показывает время регистрации и явно выделяет текущий адрес.
- Очистка является локальной для телефона: другие устройства могут ещё хранить старый адрес до получения отдельного отзыва.
