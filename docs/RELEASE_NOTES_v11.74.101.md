# APU v11.74.101 — «Вас пригласили?» в онбординге: ранг за друга доходит до конца

## Что изменилось (раунд 204)

Владелец (после принятия р203): «Нужно когда приглашаем друга в APU и
присылаем ему АПК файл то нужно чтобы за приглашенного друга ранг
поднимался. Может то что я отправляю АПК файл ему привязывать свой
оригинальный номер чтобы если именно этот файл установил то он за
считался как реферал и приглашаемому прибавился ранг».

### Что уже было

Реферальная атрибуция существует целиком (data/referral/, раунды 49+):
- подписанный токен приглашения (ядро: create/verify_referral_invite_token)
  + подписанная привязка identity (create_identity_signing_binding);
- цепочка: друг добавляет пригласившего по ссылке → tokq (короткая
  apu://-ссылка токен не несёт - слишком длинный для QR) → tokr
  (подпись тем же токеном) → атрибуция → проверка → +1 в
  qualified_direct_count → ранг (ReferralRankStore.changes);
- CreditPolicy: только новички (identity НЕ старше ссылки),
  идемпотентность по узлу, самоприглашение и повторы не двигают,
  транспортный senderId обязан совпасть с подписанной привязкой.

### Разрыв, который закрыт

После установки APK друг проходил онбординг (имя → генерация → «вот
твоя ссылка») и НИКТО не напоминал добавить пригласившего по ссылке -
атрибуция не срабатывала, ранг не рос. Теперь на финальном шаге
онбординга блок «Вас пригласили в APU?»: вставка сообщения друга
ЦЕЛИКОМ (extractLink вынимает ссылку из текста, р174), кнопка
«Добавить пригласившего» → личная ссылка ведёт в AddContact (вся
цепочка атрибуции - сама), ссылка на группу - в карточку «Вступить».
Проверка валидности на лету: кнопка активна только при разибраемой
ссылке (InviteLinkParser.parse / GroupInviteLinks.parseTarget).

### Почему НЕ внутри APK

APK подписан (v2/v3): изменение байтов ломает подпись - файл перестанет
ставиться и обновляться. «Привязкой» к пригласившему служит ссылка в
том же сообщении, что и APK; онбординг теперь гарантирует, что друг её
введёт. Имя файла APK менять бессмысленно: после установки Android не
отдаёт приложению исходное имя файла.

НЕ тронуто: ядро, E2E, MQTT, APK-сборка, реферальная криптография.
