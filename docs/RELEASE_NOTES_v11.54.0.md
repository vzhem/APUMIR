# APU v11.54.0

Внизу главного экрана появилась панель разделов, а поиск стал общим — по чатам, группам и каналам сразу.

- Нижняя панель с разделами «Чаты», «Контакты», «Группы», «Избранное» и «Настройки» — она видна на всех этих экранах, текущий раздел подсвечен.
- Поиск теперь ищет одновременно по чатам, группам и каналам: находки больше не прячутся внутри открытой вкладки.
- Кнопка поиска стала объёмной и заметной.
- Справа у длинных списков появился бегунок прокрутки — видно, где вы находитесь.
- В поиске групп при пустой строке сразу показываются открытые группы и каналы сети.
