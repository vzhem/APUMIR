# APU v11.74.308 — Голосовые сообщения в группах

Записывайте голосовые сообщения прямо в групповом чате: нажмите значок микрофона.

- Запись с индикатором времени; остановите и отправьте или отмените.
- В пузыре голосовое показано волной и длительностью; нажмите «играть», чтобы слушать.
- Пока играет, сыгранная часть волны подсвечивается.
- Голосовое, которое ещё не загружено на устройство, открывается как обычный файл: сначала загрузите его.

Для записи нужен доступ к микрофону; приложение запросит его при первом нажатии.
