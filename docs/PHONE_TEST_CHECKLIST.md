# Проверки сборки и чек-лист перед тестами на телефоне

## Что подтверждено исходниками

- [x] В восстановленном дереве найден полный путь историй: `ChatListViewModel.publishStory()` вызывает `StoryStore.publish/encodePackets`, затем отправляет пакеты контактам через `ChatRepository.sendStoryPacket()`.
- [x] Входящий путь: `ChatRepository.saveIncomingMessage()` распознаёт пакет и передаёт его в `StoryStore.receive()`; экраны чатов читают активные истории через `StoryStore.active()`. Инициализация хранилища есть в `MessengerApplication`.
- [x] `ContentAddressedChunks` используется только в контуре личных фотоисторий; это не общая раздача файлов, групповых сообщений или каналов.
- [x] Отдельный мобильный файловый UDP/NAT-путь (`FileUdpChannel`/`FileUdpWire`/`FileTransferRouter`) присутствует в исходниках. Он не заменяет онлайн-помощников для обычных сообщений.

Отметки выше подтверждают наличие связей в исходниках, а не работу интерфейса или сети на устройстве.

## Что пока нельзя утверждать

- Наличие UI-вызовов не равно успешной пользовательской проверке на устройстве.
- Зелёные JVM/CI-тесты не подтверждают реальный NAT, произвольные мобильные сети, расход батареи или полезную ёмкость роя.
- Подписанная квитанция подтверждает конкретный принятый пакет, но не уникальность человека и не честность вклада.
- Content-addressed фотоистории не означают готовую раздачу контента для групп/каналов; она остаётся задачей следующих этапов.
