# APU v11.70.17

Резервная копия теперь может обновляться сама.

- Сделали копию в файл — под ней появляется карточка «Обновлять копию автоматически». Выбираете период (день, неделя, месяц; по умолчанию неделя), нажимаете «Включить» — и телефон сам перезаписывает этот же файл тем же паролем. Момент выбирает система: не при низком заряде и не при почти полном хранилище, обычно ночью; интернет не нужен.
- Пароль хранится только на этом телефоне, в защищённом хранилище (Android Keystore). Никуда, кроме выбранного вами файла, копия не уходит.
- На карточке видно, куда пишется копия, когда обновилась в последний раз и когда примерно следующее обновление. Кнопка «Обновить сейчас» — не дожидаясь срока; «Выключить» — стереть расписание и пароль.
- Копия сначала целиком собирается в служебном файле приложения и только потом переливается в ваш файл, поэтому обрыв посреди работы (телефон выключился, система остановила фон) не портит единственную копию.
- Если файл удалён или перемещён, сменился профиль на телефоне или пароль не прочитался — автообновление останавливается и об этом говорит уведомление с причиной; запись в файл поверх чужой копии невозможна.
- Ограничения: обновлять можно только файл, к которому хранилище даёт постоянный доступ (папки «Файлов» телефона, карта памяти, большинство облачных приложений подходят; если приложение-хранилище отказало — сохраните копию в другое место). Работает по правилам фонового режима Android: точного часа нет, есть окно в конце периода.

Обновление получают все: окно с предложением обновиться появится при запуске.
