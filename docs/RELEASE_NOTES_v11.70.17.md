# APU v11.70.17

Два дела в одном выпуске: резервная копия теперь обновляется сама, а файл для того, кто не в сети, хранят два телефона вместо одного.

## Резервная копия обновляется сама

- Сделали копию в файл — под ней появляется карточка «Обновлять копию автоматически». Выбираете период (день, неделя, месяц; по умолчанию неделя), нажимаете «Включить» — и телефон сам перезаписывает этот же файл тем же паролем. Момент выбирает система: не при низком заряде и не при почти полном хранилище, обычно ночью; интернет не нужен.
- Пароль хранится только на этом телефоне, в защищённом хранилище (Android Keystore). Никуда, кроме выбранного вами файла, копия не уходит.
- На карточке видно, куда пишется копия, когда обновилась в последний раз и когда примерно следующее обновление. Кнопка «Обновить сейчас» — не дожидаясь срока; «Выключить» — стереть расписание и пароль.
- Копия сначала целиком собирается в служебном файле приложения и только потом переливается в ваш файл, поэтому обрыв посреди работы не портит единственную копию.
- Если файл удалён или перемещён, сменился профиль на телефоне или пароль не прочитался — автообновление останавливается и об этом говорит уведомление с причиной. После восстановления из копии расписание сбрасывается: включите его заново для нового файла.
- Ограничения: обновлять можно только файл, к которому хранилище даёт постоянный доступ («Файлы» телефона, карта памяти, большинство облачных приложений; если приложение-хранилище отказало — сохраните копию в другое место). Точного часа нет — есть окно в конце периода, как у всех фоновых задач Android.

## Рой, этап 8: файл для отсутствующего хранят два телефона

- Раньше файл для получателя, которого нет в сети, уходил на хранение одному общему контакту; если тот телефон пропадал, файл ждал возвращения отправителя. Теперь отправитель, пока сам в сети, отдаёт копию и второму хранителю. В пузыре файла: «На хранении у 2 телефонов, получатель заберёт при появлении».
- Когда получатель появляется, он берёт файл сразу у обоих: сам говорит каждому хранителю, какие куски прислать, — они отдают разные части, а не одну и ту же. Большой файл приходит быстрее, пропажа одного хранителя не останавливает приём.
- Как только файл собран, оба хранителя освобождают место. Если получатель со старой версией подтвердил только одному, второго отпускает отправитель — копии не висят до срока.
- Доверие не изменилось: хранители видят только зашифрованные куски, получатель проверяет подпись отправителя, чужие файлы принимаются только от контактов и в пределах «Места под пересылку». Со старыми версиями совместимо.

Обе части на телефонах ещё не проверены — напишите, что увидели. Обновление получают все: окно с предложением обновиться появится при запуске.
