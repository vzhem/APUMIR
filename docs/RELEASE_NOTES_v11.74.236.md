# APU v11.74.236 — Подсказки групп, чатов и синхронизации на английском

Длинные подсказки на экранах групп, списка чатов, избранного и переноса профиля теперь выводятся на выбранном языке целиком, одной фразой, без склеивания кусков.

- Подсказки про QR-код для входа и ожидание сканирования собеседником.
- Условие создания групп с ранга «Проводник» и вступления по ссылке.
- Пустой список каналов и подсказка про кнопку создания чата.
- Подсказка избранного про пересылку файлов и постов.
- Подсказки переноса профиля: автоматическая синхронизация, поиск устройств и периодическая проверка копии.
