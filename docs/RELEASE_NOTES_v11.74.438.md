# v11.74.438

**Понятное подтверждение возврата настроек**

- После глобального и секционного возврата настроек APU показывает карточку «Готово» с результатом операции.
- Такие же подтверждения появились для оформления, цветов, фильтра чтения, обоев чата, локальных настроек чата и редакторов фото- и видеоисторий.
- Возврат значений по умолчанию для скорости и эффекта голоса, фильтров, фона видеоистории и текста SOS теперь тоже сопровождается понятным сообщением.
- Сбросы сохраняют прежнюю область действия: сообщения, контакты, профиль, файлы, ключи устройства, подписанные receipt, referral-данные, членство в группах, резервные копии и APU-карточки не удаляются.
- Добавлены русская и английская локализации.
