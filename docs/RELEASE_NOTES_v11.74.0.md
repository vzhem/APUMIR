# APU v11.74.0

Обновляться стало проще: раздел «Настройки → Обновления» теперь делает почти всё сам.

- Файл обновления, скачанный с официального сайта, сам появляется в разделе «Обновления»: версия читается из самого файла, останется нажать «Обновить».
- Если новая версия нашлась и на официальном сайте, и у соседей по сети — в карточке будут обе кнопки, откуда качать, на ваш выбор.
- По сети обновление качается кусочками сразу с нескольких телефонов, где оно есть, — так быстрее.
- Имя и версия файла подставляются сами: выбрать APK из своих файлов и раздать его соседям можно без ручного ввода.
- Всё остальное — как в v11.73.0.

Обновление получают все: окно с предложением обновиться появится при запуске.
