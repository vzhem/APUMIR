# APU v11.74.100 — источник над карточками; стикеры картинкой; «✓ Отправлено»

## Что изменилось (продолжение раунда 203)

Владелец (скрин лички с Server67, пересылка стикера из группы):
«Гифка приходит но без ссылки. А стикеры приходят кодом. И нужно когда
поделился чтобы если отправилось то приходило всплывающее уведомление
по середине экрана что отправлено.»

### Шапка над карточками

Гифка-пересылка в личке рисовалась карточкой (GifRefCard) БЕЗ шапки-
источника: ветка карточки стоит до пузыря. Личка теперь рисует шапку
«↩ Переслано из «…»» САМА над карточками гифки и файла/стикера
(локальная CardForwardHeader, кликабельная, resolveForwardTap).

### Стикеры не «кодом»

Пересланный стикер/файл - это визитка APUFILE1 БЕЗ личной передачи
(transfer не создаётся: offer-пакетов при пересылке не было), поэтому
личка печатала её как текст. Теперь:
- если стикер есть в библиотеке стикеров получателя (стикер-рой
  раздаёт всем; StickerLibrary.fileOf по sha256) - рисуется
  анимированной картинкой (StickerAnimated), тап - PhotoViewer;
- нет - визитка «📎 имя (размер) + файла нет на этом телефоне».
ChatDetailViewModel.localSwarmFile - обёртка fileOf.

### «✓ Отправлено» по центру

ForwardSentOverlay (ui/components/ForwardDialogs.kt): тёмная плашка
с «✓ Отправлено» ПО СЕРЕДИНЕ экрана, авто-скрытие 2.2 с (LaunchedEffect).
Успех пересылки (личка: друг/группа+тема/канал+пост; группы: те же) -
оверлей вместо тоста «Переслано: …»; неудача - тост «Не удалось
переслать». Оверлей кладётся sibling-ом к Scaffold - поверх экрана
(Box обёртки NavHost, р202).
