# APU v11.48.0

Реакции ставятся одним нажатием, в посты канала можно прикреплять фото, а из «Избранного» — вернуться к оригиналу.

- Одно нажатие на сообщение или пост открывает выбор реакции; нажатие на уже поставленный значок позволяет сменить его или убрать.
- В посты канала можно прикреплять фото, а лента канала теперь растёт вниз и при открытии показывает самое свежее.
- В действиях с сообщением появилось «Выделить часть текста» — копировать целиком больше не обязательно.
- У записей «Избранного» появился переход к оригиналу: открывается тот самый чат, тема группы или лента канала.
- В разделе «Группы» пустой список теперь подсказывает про группы, а не про чаты.
