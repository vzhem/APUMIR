# APU v11.46.0

Пригласить человека в свои группы теперь можно прямо из списка контактов.

- В меню контакта появился пункт «Пригласить в группу».
- Открывается список ваших групп и каналов с поиском по названию.
- Можно отметить сразу несколько групп и отправить приглашения одним сообщением.
- В приглашении есть и ссылка на группу, и ссылка на установку APU — годится и тем, у кого приложение уже есть, и новичкам.
