# APU v11.74.303 — Плавная загрузка и стеклянные шапки

Лента группы открывается с заглушками вместо пустого экрана, новые сообщения появляются плавно, а шапки стали легче поверх обоев.

- Группы: при открытии показываются очертания сообщений, пока идёт загрузка.
- Группы и личные чаты: сообщения плавно появляются и сдвигаются при обновлении ленты.
- Шапки групп и личных чатов: полупрозрачная полоса с тонкой светлой линией.
