# APU v11.74.282 — Резервные копии, сеть и время сообщений на выбранном языке

Экраны резервного копирования, статус подключения и отметка «Вчера» в сообщениях теперь выводятся на выбранном языке.

- Настройки автообновления копии (период, дата следующего обновления, размер) переведены.
- Статус подключения («Подключён», «Подключение…», «Через ретранслятор», «Нет соединения») переведён.
- В пузырях сообщений вчерашний день показывается как «Вчера» / «Yesterday».
- Размеры файлов в резервных копиях выводятся с единицами выбранного языка.
