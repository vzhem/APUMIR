# APU v11.74.32 — удаление своих сообщений

## Новое: «Удалить у себя» и «Удалить у всех»

Долгое нажатие на **своём** сообщении — теперь там два новых пункта:

- **«Удалить у себя»** — сообщение исчезает только на этом телефоне.
- **«Удалить у всех»** (с подтверждением) — сообщение исчезает и у вас,
  и у собеседника / всех участников.

Работает в личных чатах, в группах и в комментариях каналов. Заодно
подчищаются реакции удалённого сообщения и куски длинного текста,
а превью в списке чатов пересчитывается — стёртый текст там не болтается.

## Как это работает честно

- «Удалить у всех» может только **автор** сообщения (в группе и владелец).
- Собеседник стирает ровно сообщение этого отправителя — подделать чужое
  удаление нельзя.
- Если собеседник сейчас недоступен, «у всех» не сработает и покажет
  отказ — половинного удаления не будет.
- У кого стоит старая версия приложения, там сообщение останется —
  лечится обновлением всех телефонов.

## Напоминание

Обновите **все** телефоны. Патч для компактного обновления вечером:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\ci\make_update_patch.ps1 -FromTag v11.74.31 -ToTag v11.74.32 -Upload
```
