# APU v11.74.311 — Отложенные и тихие сообщения

Теперь можно отправить сообщение позже или без звука у получателя.

- Рядом с кнопкой «Отправить» появилась кнопка «Ещё»: отправить сейчас, через 15 минут, через час или завтра в 9:00.
- Отложенное сообщение видно над полем ввода, его можно отменить до отправки. Оно уйдёт, даже если приложение закрыто.
- «Без звука»: получатель увидит сообщение без звукового сигнала в уведомлении.
- Работает в личных чатах, группах и группах с темами. Пока только для текста, без вложений.

Известное ограничение: на старых версиях приложения у тихого сообщения перед текстом виден служебный префикс.
