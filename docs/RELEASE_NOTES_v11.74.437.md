# v11.74.437

**Безопасный возврат настроек к значениям по умолчанию**

- Добавлен общий сброс настроек с выбором категорий и отдельный сброс каждого раздела.
- Можно вернуть по умолчанию тему, размер текста, обои и их оттенок, цвета текста и имени, фильтр чтения, язык, скорость голосовых сообщений и эффект голоса.
- Для скорости голосовых сообщений добавлен понятный пункт `1× · По умолчанию`; для эффекта — `Обычный голос · По умолчанию`.
- В меню личного чата появился сброс его локальных настроек с возможностью отменить действие.
- Сброс общего фона группы или канала доступен только владельцу или администратору с соответствующим правом и не изменяет личные настройки участников.
- Сброс не удаляет сообщения, контакты, профиль, файлы, ключи устройства, подписанные receipt, referral-данные, членство в группах, резервные копии или APU-карточки.
- Добавлены русская и английская локализации.
