# APU v11.52.0

Раздел QR-кода листается пальцем, а значок ранга стал объёмной анимированной медалью.

- Вкладки «Сканировать» и «Мой код» переключаются свайпом; кнопки сверху работают как раньше.
- Камера включается только на своей вкладке и не занимает устройство впустую.
- Значок ранга на главном экране — объёмная золотая медаль на наградной ленте: она покачивается, и по ней пробегает световой отблеск.
- Та же медаль появилась в разделе «Ранги и возможности».
