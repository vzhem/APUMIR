APU v11.39.0

Починка зависания: приложение перестаёт «не отвечать» на телефонах с накопленной перепиской.

- Устранено зависание с окном «Приложение не отвечает»: сведения об именах, которые телефоны пересказывают друг другу, больше не заставляют приложение без остановки перебирать список чатов.
- Проверка списков при запуске стала мгновенной: она больше не переписывает то, что и так в порядке.
- Собеседники, чьи имена отличались только заглавной буквой, теперь считаются одним человеком — «Сервер5» и «сервер5» больше не висят двумя записями.

Известное ограничение: голосовые звонки между разными сетями пока нестабильны — это отдельная задача.
