# APU v11.74.19 — гифки из роя: три хранителя, быстрее

## Главное

**Просьба гифки уходит сразу ТРЁМ лучшим хранителям** (свежий онлайн —
в приоритете рейтинга). Гифку приносит самый быстрый/доступный:

- остальные хранители автоматически останавливаются — один и тот же
  файл никогда не качается дважды параллельно;
- если выбранный источник замолчал дольше 10 минут — дорогу получает
  следующий;
- статус в окне гифок честный: «Попросил у Мама (и ещё 2) — принесёт
  самый быстрый».

Так сценарий «котик есть на 10 телефонах» работает как надо: новый
телефон тянет его с того из десяти, кто сейчас быстрее всех на связи.

## Прочее

В группах и каналах файлы уже умели качаться полосами с нескольких
телефонов — здесь ничего не менялось. Шифрование и сервер — без
изменений.
