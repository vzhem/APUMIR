# APU v11.70.3

Репост поста канала теперь уходит вместе с фотографиями.

- «Поделиться постом» передаёт в другой мессенджер или почту все фотографии поста файлами, а текст и ссылка «Открыть в APU» идут подписью к ним. Одно фото - обычная отправка, несколько - все сразу.
- «В избранное» сохраняет пост вместе с фотографиями: в «Избранном» они видны, и оттуда пост можно переслать дальше тоже с фото.
- Сообщение группы с картинкой сохраняется в «Избранное» картинкой, а не служебным текстом.

Обновление получают все: окно с предложением обновиться появится при запуске.
