# APU v11.74.33 — окно обновления с человеческим текстом

Что исправлено: окно «Доступно обновление» показывало заметки релиза
как есть — с разметкой и командами, «каким-то кодом». Теперь в окне
только короткое описание: заголовок и первая секция заметок чистым
текстом, без решёток, звёздочек и блоков команд.

Полные заметки с деталями по-прежнему на странице релиза на GitHub.

## Напоминание

Обновите все телефоны. Патч для компактного обновления вечером:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\ci\make_update_patch.ps1 -FromTag v11.74.32 -ToTag v11.74.33 -Upload
```
