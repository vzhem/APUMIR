# APU v11.74.174

В этой версии расширена синхронизация между устройствами одного аккаунта и добавлены удобные возможности для чатов.

- Архивирование и режим «Без звука» доступны для личных чатов и групп и синхронизируются между устройствами. Уведомления снова включаются по окончании выбранного срока.
- В группах и темах каналов появился индикатор «печатает…».
- Удаление сообщения «у меня» синхронизируется со вторым устройством; накопленные исходящие сообщения досылаются, когда устройство возвращается в сеть.
- Вложения групп и каналов доступны на втором устройстве. Крупные файлы до 256 МБ можно запросить вручную и докачать с места остановки.
- Перед установкой сделайте резервную копию аккаунта.
