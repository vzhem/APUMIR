# v11.74.530 — крупный файл доливается, а не начинается заново

Собрано из ветки `arena/b19361a0-apumir`.

- Выкладка на официальный сайт переживает обрыв FTP на крупном файле: сервер
  просит продолжить запись с уже принятого размера (`REST`), поэтому
  многомегабайтный APK не заливается с нуля после каждого таймаута.
- Имя временного файла переживает переподключение — иначе продолжать было бы
  нечего.
- Если сервер не умеет продолжать (или отдаёт не тот размер), заливка честно
  начинается заново; поверх неизвестного ничего не дозаливается.
- Публикация (переименование) выполняется только при совпадении серверного
  размера и локальной контрольной суммы.
- Правила приоритетов из `v11.74.529` не менялись.

**Как проверить:** `https://apu.clan.su/downloads/latest.json` показывает
`v11.74.530`; работа workflow **Publish release to official site** зелёная,
в её журнале видно `Staging app-release.apk from N of M bytes` при повторе.
