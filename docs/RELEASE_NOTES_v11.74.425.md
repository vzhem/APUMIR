# v11.74.425

**Папки с чатами — как в Telegram.**

Новый раздел «Папки с чатами» (Настройки → Внешний вид → «Папки с чатами», а также меню «⋮» на главном экране):

- **Рекомендованные папки** добавляются в один тап: «Новые» (чаты с новыми сообщениями) и «Личные» (сообщения из личных чатов) — их состав обновляется сам.
- **Свои папки**: «Создать новую папку» → название и галочки напротив нужных чатов, групп и каналов.
- Папки можно **перетаскивать за ручку** вверх/вниз (или через меню «⋮»: выше/ниже), переименовывать и удалять. Удаление папки чаты не трогает.

Каждая папка сразу становится **вкладкой главного списка** — в одной полоске с «Все», «Чаты», «Группы» и листается тем же свайпом. На вкладке папки — счётчик чатов с непрочитанным.
