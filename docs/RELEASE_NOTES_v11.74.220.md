# APU v11.74.220 — Кнопка «Перевести» для входящих сообщений

- Под входящим текстом на другом языке появилась кнопка «Перевести». Она работает, даже когда переключатель «Переводить входящие сообщения» выключен.
- Нажатие переводит только это сообщение. Перевод появляется над текстом, а «Показать оригинал» переключает обратно.
- Если сообщение уже на языке приложения, перевода не будет.
- Языковой пакет (около 30 МБ) скачивается при первом переводе. Для автоматического перевода всех сообщений по-прежнему нужен переключатель в настройках.
