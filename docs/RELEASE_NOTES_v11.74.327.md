# Более удачный выбор помощников

- Телефон учитывает подтверждённые доставки и время ответа при выборе пути к получателю.
- Неудачные пути временно уступают место другим; недоступность одного получателя не ухудшает связь с остальными.
- Резервный путь по-прежнему помогает при задержке первого.

Доступность связи зависит от сети и наличия подходящих помощников.
