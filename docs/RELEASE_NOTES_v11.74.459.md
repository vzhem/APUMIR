APU 11.74.459

Таблица «Лидеры по сердечкам» больше не показывает одного участника дважды.

- Раньше человек с несколькими устройствами (или после переустановки) занимал в таблице две строки подряд — с разными числами сердечек. Теперь он занимает одну строку с лучшим результатом.
- Место в шапке профиля и место в таблице всегда совпадают.
- Участники с разными именами по-прежнему считаются отдельно, а строка без имени никого не объединяет с другими.
- Если объединение было, под заголовком таблицы появляется короткое пояснение.

Существующие сообщения, файлы и настройки не удаляются.
