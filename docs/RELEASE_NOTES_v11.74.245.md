# APU v11.74.245 — Сообщения настроек на английском

Сообщения экрана настроек, которые формирует модель настроек: проверка обновлений, адресная книга, очистка передач и ошибки открытия файлов, теперь выводятся на выбранном языке.

- Ошибки открытия и чтения файла, ошибка установки обновления.
- Статусы поиска обновлений у соседей и сохранения адресной книги.
- Итоги очистки: остановленные зависшие отправки и очищенные передачи.
