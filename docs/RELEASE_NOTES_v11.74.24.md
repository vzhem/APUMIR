# APU v11.74.24 — единый каталог гифок и синяя точка «уже в нашей сети»

## Каталог стал единым

Вкладок больше нет — **одна сетка**, где подряд:

- ваши гифки (с превью, метка «мой»);
- гифки сети (метка «у N» — лежат на других ваших телефонах);
- гифки внешнего каталога (поиск).

## Синяя точка — «уже в нашей сети»

Приложение само определяет, есть ли гифка в нашей сети:

- **синяя переливающаяся точка** в правом верхнем углу — гифка уже
  лежит в сети (у вас или на другом вашем телефоне);
- выбрав такую гифку, вы **не тратите внешний каталог**: своя —
  отправится мгновенно с телефона, чужая — придёт с того телефона,
  где она лежит;
- под сеткой — пометка, что означает точка:
  «синяя точка — гифка уже в нашей сети: придёт с телефонов своих,
  внешний каталог не тратится».

Свою гифку по-прежнему можно добавить кнопкой «+ Своя».
