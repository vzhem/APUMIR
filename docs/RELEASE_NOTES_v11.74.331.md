# Этап 4 — статистика и anti-abuse (начат, без измерений)

- Добавлен `SwarmContributionStats` (завершённые доставки/отказы по peer; не доказательство честности).
- Anti-abuse остаётся на уровне существующего dedup + отказ без новых подписанных cards (нет измерений ёмкости).
- Load / battery / NAT-стабильность не проверялись; не обещать ёмкость или работу через произвольный NAT.
- Продолжение только после реального устройства.
