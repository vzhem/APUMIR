# APU v11.74.16 — GIF-кнопка и доставка после обновления

## Главное (по замечаниям владельца)

1. **Кнопка GIF в личном чате больше не накладывается на скрепку.**
   Раньше она рисовалась поверх скрепки (обе в одной клетке). Теперь
   «скрепка» и «GIF» — две отдельные кнопки рядом, как в группах.
2. **Сообщения больше не пропадают после обновления приложения.**
   Найдены две причины тихой потери (отправитель при этом видел
   «доставлено»):
   - внутренняя очередь событий при переполнении (лава presence/gossip
     и кусков файлов сразу после старта обновлённого приложения)
     выбрасывала самые старые события — ими бывали входящие сообщения.
     Теперь текст переписки и подтверждения доставки не выбрасываются
     никогда: первыми уходят служебные события, потом куски файлов;
   - повторная доставка сообщения, которое ядро успело отметить
     «показанным» до гибели процесса, давилась пометкой «уже доставлено»
     — и навсегда скрывалась. Теперь пометка не блокирует показ:
     дубликаты отфильтровывает база по номеру сообщения.

## Прочее

+4 теста ядра на сохранность сообщений при переполнении очереди.
Без изменений шифрования и сервера.
