# APU v11.74.247 — Онбординг и MTProto-прокси на английском

Сообщения первого экрана знакомства и экрана прокси, которые формирует модель, теперь выводятся на выбранном языке.

- Онбординг: проверка никнейма, имени и пароля, занятый никнейм, ошибка создания профиля.
- Прокси: добавление, выбор и удаление, импорт из буфера обмена, сбор и проверка прокси.
- Подсказки о рангах, с которых открываются ручные прокси, автовыбор и автосбор.

Пока на русском: «Собираем прокси» уже переведено, но названия рангов в тексте используют английские названия только в английской локали.
