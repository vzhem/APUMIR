APU v11.30.0

Главное: в личных чатах появились голосовые звонки.

- Кнопка трубки в шапке чата — позвонить собеседнику.
- Входящий звонок приходит на весь экран с рингтоном, даже из свёрнутого приложения.
- «Принять / Отклонить / Завершить», выключение микрофона и громкая связь прямо во время разговора, таймер разговора.
- Голос зашифрован для каждого звонка отдельно; в одной Wi-Fi сети звук идёт напрямую между телефонами — быстро и без всяких серверов.
- Статусы на экране: «Вызов…», «Гудки…», «Соединение…», понятные причины конца («Занято», «Нет ответа»).

Известное ограничение: звонок, где оба собеседника далеко друг от друга и без общей сети, пока идёт в экономном качестве и может отставать на слабом интернете; полноценную связь в таких случаях добавим отдельным обновлением.
