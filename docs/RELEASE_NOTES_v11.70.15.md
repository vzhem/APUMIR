# APU v11.70.15

Звонки через мобильную сеть: телефоны теперь пробуют соединиться напрямую, минуя ретрансляторы.

- Во время звонка каждый телефон узнаёт свой внешний адрес и обменивается им с собеседником, после чего оба пробивают прямой путь друг к другу. Если это удалось, голос идёт напрямую — с меньшей задержкой и без зависимости от общедоступных ретрансляторов. На экране звонка в этом режиме подпись «Через интернет — прямое соединение».
- Если прямой путь не пробился (так бывает у некоторых операторов), звонок остаётся на прежнем интернет-канале — как в v11.70.14. Если прямой путь оборвался посреди разговора (например, сменилась сеть), голос сам возвращается на интернет-канал, звонок не рвётся.
- В одной Wi-Fi всё по-прежнему: прямое соединение без сжатия.
- Внешние службы определения адреса опрашиваются с коротким ожиданием: если они недоступны, звонок просто идёт по обычному пути.
- Известное ограничение: прямое соединение возможно не у всех операторов; на телефонах эта версия пока не проверена — напишите, как слышно.
- Со старыми версиями APU всё работает как раньше: новые возможности включаются только когда обновлены оба телефона.

Обновление получают все: окно с предложением обновиться появится при запуске.
