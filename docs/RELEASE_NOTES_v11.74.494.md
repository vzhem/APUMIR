В этой версии добавлены видеозвонок из меню личного чата и ручное управление прочитанностью.

- Начинайте видеозвонок прямо из меню личного чата.
- Переключайте состояние чата между «прочитано» и «непрочитано» из того же меню.
- Чаты, отмеченные непрочитанными, появляются во вкладке «Не прочитано»; открытие чата снимает отметку.

**Известное ограничение:** отметка непрочитанного сохраняется только на этом устройстве и не синхронизируется между устройствами.
