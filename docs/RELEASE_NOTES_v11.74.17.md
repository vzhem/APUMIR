# APU v11.74.17 — гифки: реакция, анимация, скорость

## Главное (по замечаниям владельца после полевых испытаний GIF)

1. **Реакция на гифке — теперь работает у всех.** Долгое нажатие на
   картинке/гифке в личном чате открывает то же меню действий, что у
   текстового сообщения, — внутри «Поставить реакцию»; под пузырём
   видна строка реакций. Раньше жест открывал меню файла и только у
   принятых картинок, поэтому реакцию не мог поставить никто.
2. **У отправителя гифка тоже анимируется.** Превью исходящей гифки —
   сама гифка, а не статичный кадр.
3. **«Приложение не отвечает» при отправке гифки — убрано.** Отправка
   файлов полностью ушла в фоновый поток: главный поток больше не
   блокируется на секунды, система перестаёт показывать ошибку.
4. **Повторная отправка той же гифки больше не перекачивает весь
   объём.** Если получатель уже принял и проверил такой же файл (тот
   же отправитель, тот же чат), повторная передача завершается на его
   телефоне локальной копией: получатель мгновенно видит гифку,
   отправителю сразу уходит подтверждение — гигабайты по медленному
   пути не гоняются второй раз.

## Прочее

Без изменений шифрования и сервера.
