# APU v11.74.246 — Избранное и сообщения групп на английском

Сообщения экрана «Избранное» и модели групповых чатов, которые приходят из модели, теперь выводятся на выбранном языке.

- Избранное: удаление, сохранение файлов, стикеров и GIF, ошибки «Файл больше не доступен» и «Не удалось поделиться».
- Группы: ошибки стикеров, GIF и файлов, статусы поиска держателей, выбор темы и создание опроса.
- Каталог GIF: сообщение о перегрузке сервера.

Пока на русском: «Сохранено: …» в избранном, где к тексту присоединяется имя файла.
