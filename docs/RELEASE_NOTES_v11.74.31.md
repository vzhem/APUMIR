# APU v11.74.31 — гифка больше не задваивается

## Что было

Вы отправляли гифку (например, выбрав её в каталоге сети) — и в чате
появлялись ДВЕ карточки: карточка-ссылка от вашего лица и второй пузырь
«Сохранено ✓» с той же гифкой. Второй пузырь — это байты, которые телефон
тихо забрал у хранителя: система вставляла их в чат как отдельное
«полученное», хотя раунд 128 договорился — байты ездят беззвучно,
в чате одна карточка.

## Что стало

- Байты гифки больше **не вставляются в чат** — они тихо ложатся в
  библиотеку, и карточка-ссылка оживает сама.
- Один отправленный файл = **одна карточка**.
- Гифка, присланная как обычный файл через скрепку (её никто не просил
  из каталога), по-прежнему показывается пузырём — это обычный файл.

## Напоминание

Обновите **все** телефоны. Патч для компактного обновления вечером:

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\ci\make_update_patch.ps1 -FromTag v11.74.30 -ToTag v11.74.31 -Upload
```
