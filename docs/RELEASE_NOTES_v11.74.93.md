# APU v11.74.93 — приглашения уносят с собой установочный APK

## Что изменилось (раунды 197-198)

Владелец: «когда мы приглашаем друга из другой сети с внешнего ресурса,
то нам нужно к пригласительному сообщению прикладывать свежий последний
АПК файл. Чтобы друг смог установить сразу из входящего сообщения»;
затем: «для приглашений в группы и каналы если это на внешний ресурс
тоже нужно прикрепить как файл... А лучше добавить галочку прикрепить
как файл или нет».

### Источник файла

Свежий APK на каждом телефоне - это САМ УСТАНОВЛЕННЫЙ файл
(applicationInfo.sourceDir), тот же, что рой раздаёт (ensureSelfSeeding).
Перед отправкой копия в cacheDir/invite/APU-v<версия>.apk (у base.apk
некрасивое имя; у FileProvider уже есть root-path «root» - его хватило);
переиспользуем копию, если версия и размер совпали, старые версии
подчищаем. Копирование в фоне (Thread) - 40 МБ не морозят интерфейс.
Intent ACTION_SEND: type = vnd.android.package-archive, EXTRA_TEXT +
EXTRA_STREAM, FLAG_GRANT_READ_URI_PERMISSION. Любая неудача - обычный
текст со ссылкой, как раньше (fallback).

### Раунд 197: приглашение другу - всегда с APK

AppShare.shareInvite -> shareTextWithApk (thread + fallback).
Точки: Контакты «Пригласить», профиль «Поделиться» (через ShortShare).

### Раунд 198: группы/каналы наружу - галочка (по умолчанию ВКЛ)

AppShare.shareGroupInvite/shareGroupInvites + параметр attachApk
(по умолчанию false для совместимости). Галочка «Приложить
установочный файл (APK)» в ТРЁХ местах:
- GroupsScreen: диалог «Пригласить в группу/канал» (кнопка «Отправить
  ссылку»);
- GroupAdminScreen: карточка ссылки-приглашения (рядом с «Поделиться»);
- ContactsScreen: InviteToGroupsDialog (кнопка «Другим приложением»,
  onShare получил второй аргумент).
Внутри APU (отправка сообщением в чат, карточки приглашений р189) -
без вложения: получатель уже с APU.

Грабли: check151 красный - пропустил внутренний вызов
onShare(selected.toList()) в confirm-кнопке диалога (annotation
"No value passed for parameter 'p2'" через Checks API); фикс ->
check152 зелёный. Урок: при смене сигнатуры колбэка искать ВСЕ
использования, включая внутренние.

НЕ тронуто: роевая раздача обновлений, UpdateChecker, ядро, E2E.
