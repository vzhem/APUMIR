# APU v11.70.0

Пересланная ссылка на пост теперь открывается сразу в APU — без браузера и без вопроса «чем открыть».

- Ссылка на пост канала из любого мессенджера ведёт прямо в APU: телефон при установке этой версии проверяет наш сервис и больше не спрашивает, каким приложением её открыть.
- Если скопировать пересланное сообщение целиком и вставить его в «Войти по ссылке», APU сам найдёт ссылку в тексте — как это всегда работало для приглашений в группы.
- Ссылка на пост внутри чатов APU открывается в самом APU, а не через браузер.
- У человека без APU ссылка ведёт на страницу с кнопкой «Установить APU» и после установки доводит до канала и записи.

Известное ограничение: если APU уже стоял до этой версии, а обновление ещё не установлено, ссылка сначала откроет браузер, и тот сам перейдёт в APU.
