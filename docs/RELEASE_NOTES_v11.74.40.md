# APU v11.74.40 — пузырь заявок на вступление; счётчик сообщений темы

## Что изменилось

### Для владельца и администраторов

- Пузырь «N заявок на вступление» появляется, когда есть ожидающие
  заявки (раньше счётчик был только бейджем в списке групп и вкладкой
  админ-панели).
- Живёт во всех видах сообщества: на главной группы/канала, в темах,
  в комментариях каналов. Содержимое не перекрывает - контент уезжает
  вниз.
- Нажатие - шторка снизу: поиск-пузырь («Поиск заявок») и
  прокручиваемый список карточек: аватар-буква, имя, «подал(а) заявку
  <время>», кнопки «Принять в группу» / «Отклонить» (склонения:
  заявка/заявки/заявок).
- Решили все - пузырь исчезает сам. Одобренный сразу становится
  участником (admitMember), отклонённому уходит отказ (JoinDecision).

### Для всех

- В списке тем под названием темы - счётчик сообщений с русским
  склонением: «653 сообщения», «3 сообщения», «5 сообщений», пусто -
  «Нет сообщений»; превью последнего сообщения - третьей строкой.
