# APU v11.74.71 — удаление своего из роя (стикеры, гифки)

## Что изменилось

Владелец: «нужно сделать чтобы можно было удалить стикер или гифку из
роя, который случайно закинул. хотя бы до того момента пока никто не
скачал».

1. StickerLibrary.deleteBySha(sha): из индекса + файл и миниатюра
   с диска.
2. GifLibrary.deleteOwn(context, sha): из индекса + .gif и .jpg
   с диска.
3. Панель: долгое нажатие на стикер в «Мои стикеры» и на свою гифку
   в «Мои» → AlertDialog «Удалить …?» с честным предупреждением, что
   скачанные другими копии не отзываются.
4. VM (личка и группы): после удаления мгновенный force-sync роя -
   каталог переобъявляется, у абонентов элемент исчезает из «Из сети».

## Границы (честно)

что просил владелец: пока никто не скачал - убирается из каталога.
