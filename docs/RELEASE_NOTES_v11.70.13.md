# APU v11.70.13

Файл дойдёт, даже если вы оба не бываете в сети одновременно.

- Раньше файл ждал, пока получатель появится в сети, - и только пока ваш телефон сам оставался в сети. Теперь, если получателя нет дольше двух минут, телефон отдаёт файл на хранение общему контакту, который сейчас в сети (выбирается лучший по рейтингу), и вы можете уходить: получатель заберёт файл у хранителя, как только появится. В чате это видно по строке «Передано на хранение, получатель заберёт при появлении».
- Хранитель содержимого не видит: к нему приходят только зашифрованные куски, ключ запечатан лично для получателя. Он знает лишь имя и размер файла. Хранит только для своих контактов и только в пределах своего «Места под пересылку» (ползунок в «Настройки → Раздача»); в строке «Занято сейчас…» видно, сколько из этого - чужие файлы на хранении. Как только получатель всё забрал, место освобождается; забытое удаляется само через неделю.
- Получатель принимает такой файл так же строго, как прямой: проверяет подпись отправителя и целиком контрольную сумму, а в чат кладёт его к отправителю, а не к хранителю.
- Телефоны старых версий хранителями не становятся - отправитель через полторы минуты тишины сам переходит к следующему контакту.

Обновление получают все: окно с предложением обновиться появится при запуске.
