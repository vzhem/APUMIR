# APU v11.74.342 — фотоистории с камерой

Создавать фотоистории стало проще: снимайте фото прямо в редакторе, добавляйте подпись и публикуйте.

- Встроенная камера позволяет переключаться между передней и задней камерой, а затем вернуться к черновику истории.
- Перед отправкой фото уменьшается и сжимается; фото из галереи и текстовые истории по-прежнему доступны.
- Отчёт «Логи» точнее показывает приём файлов и лучше скрывает служебные данные.
