# APU v11.74.4

Точечная починка связи в «жёсткой» мобильной сети — по данным диагностики с вашего телефона.

**Что оказалось на самом деле.** Ваш скриншот «Сети сообщений» показал: сеть отвечает брокеру на рукопожатие, но потом режет данные. Приложение считало такой broker «живым» и не переключалось на обходной путь. Теперь это лечится само: если прямой путь четыре раза подряд споткнулся, сессия перезапускается через wss-мост — и сообщения идут. Если сеть сменилась (например, приехали на Wi-Fi) — приложение само вернётся на прямой путь.

**Карточка «Сеть сообщений» теперь открывается.** Тапните её в «Настройки → О приложении» — увидите расшифровку (что значит tcp/wss, ConnAck, ошибка) и кнопку «Скопировать», чтобы отправить текст разработчику.

Раздача обновлений тоже продолжает работать автоматически: приложение само раздаёт свою текущую версию соседям.

Обновление получают все: окно с предложением обновиться появится при запуске.
