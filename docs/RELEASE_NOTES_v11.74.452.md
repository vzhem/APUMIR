APU 11.74.452

Сетевой обмен стал надёжнее при ограничениях сети.

- После короткого поиска прямых устройств приложение сохраняет резервный relay-канал, даже если рядом найден direct-сосед.
- При недоступности прямого TCP используется исходящий защищённый WSS/TLS-канал через relay на порту 443.
- Существующие сообщения, файлы и настройки не удаляются.
