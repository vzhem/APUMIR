# APU v11.74.173

На главном экране вкладка «Не прочитано» показывается только при наличии непрочитанных сообщений.

- Вкладка появляется, если непрочитанные есть хотя бы в одном чате, группе или канале.
- Когда непрочитанных не остаётся, вкладка автоматически скрывается.
- Если появляются новые непрочитанные сообщения, вкладка снова становится доступна.
