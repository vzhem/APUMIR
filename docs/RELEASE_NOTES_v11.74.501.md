Добавлена возможность очистки личной переписки с отправкой запроса собеседнику.

- Переписку можно очистить только на своём устройстве.
- При выборе очистки у обоих запрос ставится в очередь для доставки.
- Для выполнения запроса собеседнику нужна обновлённая версия приложения.

**Известные ограничения:** у собеседника удаляются только сообщения и файлы, известные устройству отправителя; другие сообщения и сохранённые копии могут остаться. Полное согласование очистки пока не доступно. Работа на двух физических устройствах ещё не проверена.
