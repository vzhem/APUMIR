# v11.74.402

## Видеоаватары в профиле
- В выборе аватара появилась кнопка «Видеоаватар»: выберите короткое видео из галереи (до 15 секунд) — и в вашем профиле аватар будет играть живьём, по кругу и без звука.
- Для списков чатов и собеседников из видео автоматически снимается кадр-постер: он ставится обычным аватаром и уезжает друзьям как раньше, поэтому у них видна картинка, а не пустое место.
- Видео хранится в приватной папке приложения, старое при замене удаляется. «Убрать аватар» снимает и видео, отдельно можно убрать только видео, оставив кадр картинкой.
