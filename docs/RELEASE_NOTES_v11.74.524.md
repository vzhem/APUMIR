# v11.74.524 — доставка на свёрнутый телефон

Собрано из `7e6bd9e`.

Улучшена доставка сообщений, когда получатель свернул приложение или заблокировал
экран.

- Пробуждение собеседника адресуется его собственными данными: раньше запрос
  уходил по адресу, которого не было ни у одного телефона.
- Запрос отправляется и тогда, когда сообщение уже ушло брокеру, но не было
  подтверждено, в том числе при повторе из очереди.
- В «Логах» раздел `[push]` показывает, принят ли запрос службой
  (`принято_службой=`), есть ли куда его отправить (`эпох_собеседников=`) и как
  давно проверялась сама служба.

**Как проверить:** поставить этот выпуск на оба телефона, второй свернуть и
заблокировать, отправить личное сообщение с первого.

**Известное ограничение.** Если собеседник после обновления ещё ничего не
отправлял, его телефон может не прислать данные для пробуждения — тогда в
`[push]` будет `эпох_собеседников=0`, и достаточно, чтобы он один раз написал.
