# APU v11.74.248 — Уведомления администрирования групп на английском

Короткие уведомления, которые показываются после действий администратора группы, теперь выводятся на выбранном языке.

- Участники и заявки: добавлен, исключён, заявка отклонена, передано владение.
- Ссылки-приглашения: создана, отозвана, удалена.
- Настройки группы: публичная или частная, темы включены, медленный режим выключен, аватар обновлён.
- Ошибки статистики и чтения картинки.

Пока на русском: подписи величин медленного режима (секунды и минуты).
