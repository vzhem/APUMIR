# v11.74.403

## До пяти реакций на сообщение
- Один человек теперь может поставить на сообщение до пяти разных реакций — везде, где реакции есть: личные чаты, группы, темы и каналы. Повторное нажатие на свой значок снимает только его, остальные остаются.
- «Убрать реакцию» снимает все свои значки с сообщения разом.
- В окне выбора все свои значки подсвечены золотом, виден счётчик «Ваши реакции: N из 5», а на пределе — подсказка снять один значок, чтобы поставить другой. Шестой значок не встанет и у собеседников не примется: предел держится с обеих сторон.
- Старые реакции не пропадут: база аккуратно переведена на новый вид хранения (миграция 31→32).
