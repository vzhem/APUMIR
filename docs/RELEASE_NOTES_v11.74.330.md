# Общий сборщик содержимого — базовая сборка этапа 3

- Добавлен общий `ContentAddressedChunks` с проверкой манифеста, хэшей частей и финального содержимого.
- Фото в историях теперь проверяются по полному хэшу изображения (`photoSha`) и хэшу каждой части (`chunk`), с сохранением N-1 полей (`kind=photo`, `data`, `part`).
- Старые APUSTORY1 фрагменты читаются в ограниченном режиме; новые отправления требуют `contentId`/`chunkId`.
- Локальное удаление истории (`revokeLocal`) работает; уже отправленные части не отменяются.

Ограничение: сборка прошла проверку в CI (core + Kotlin compile); независимые замеры на реальном телефоне (батарея, нагрузка, NAT) не выполнялись. Ёмкость и стабильность через произвольный NAT не обещаны.
