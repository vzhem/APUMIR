# APU v11.71.0

Надёжная связь между абонентами после перезагрузок и смены сети, обмен файлами по мобильной связи.

- Приложение теперь помнит, где находятся ваши собеседники: список адресов хранится в файле на телефоне. После перезагрузки, смены сети или переустановки APU помнит, куда искать своих, — не нужно заново «находить друг друга» через общий сервер.
- Сразу после запуска приложение проверяет, кто из них на связи, и обновляет их адреса — список поддерживается актуальным постоянно, а устаревшие записи убираются сами.
- Сообщения стали надёжнее: если получатель в сети — сообщение доходит до него напрямую, если нет — как раньше сохраняется для дальнейшей доставки.
- Файлы групп и обновления приложения теперь передаются напрямую между телефонами по мобильной связи — даже когда оба телефона вне Wi-Fi.
- Кнопка «Проверить новую версию» в настройках показывает «Обновить до vX.Y.Z» — обновление ставится прямо из приложения, а телефоны с новой версией автоматически помогают раздавать её остальным.

Известное ограничение: если оба телефона за строго защищёнными сетями, передача файла может пройти через общий сервер — тогда это работает, но медленнее.

Обновление получают все: окно с предложением обновиться появится при запуске.
