# APU v11.47.0

Реакции на сообщения и посты, плюс исправлено зависание при создании канала.

- Реакции в личных чатах и группах: долгое нажатие на сообщение — «Поставить реакцию».
- Реакции на посты канала — кнопка «Реакция» рядом с комментариями.
- Поставленные значки видны строкой под сообщением с числом; своя реакция обведена золотом, повторное нажатие её снимает.
- Исправлено зависание приложения при вводе названия новой группы или канала.
- В окне создания канала подписи больше не называют его группой.
