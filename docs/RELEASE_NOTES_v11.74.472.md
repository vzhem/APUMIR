APU 11.74.472

Теперь приложение может работать через ваш собственный MQTT-сервер, если вы не хотите зависеть от публичных.

- В настройках, в разделе «Сеть сообщений», появилась строка «Свой брокер»: по умолчанию там стоят «Публичные брокеры», как и раньше.
- Можно вписать адрес своего сервера — просто `имя`, `имя:порт`, `mqtt://…` или `tcp://…`; порт по умолчанию 1883, адрес IPv6 пишется в квадратных скобках.
- Кнопка «Проверить» сразу показывает, отвечает ли сервер по этому адресу, — можно убедиться до сохранения.
- Новый адрес начинает работать без перезапуска приложения: сообщения, которые ждали отправки, не теряются и уходят через уже выбранный сервер.
- Если в адресе опечатка и сервер не принял его, прежняя настройка остаётся в силе — связь не пропадает.
- Чтобы вернуться к публичным брокерам, достаточно очистить поле и сохранить.

Существующие сообщения, файлы и настройки не удаляются.
