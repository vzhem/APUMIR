# Надёжнее связь через телефоны-помощники

- Резервный помощник подключается быстрее, если первый задерживается.
- Пересылка через нескольких помощников защищена от повторной выдачи одного пакета.
- Во время пересылки сеть пытается открыть прямой канал между телефонами.

Доступность связи зависит от сети и наличия подходящих помощников.
