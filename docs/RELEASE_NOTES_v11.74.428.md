# v11.74.428

**Исправлены входящие голосовые сообщения.**

Голосовые сообщения, которые раньше приходили с пометкой «Ошибка (VERIFY_FAILED)» и не проигрывались, теперь принимаются надёжно:

- **Проверка при приёме**: каждый кусочек файла проверяется сразу при получении, а не только после сборки всего файла.
- **Самовосстановление**: кусочек, повреждённый при передаче, отбрасывается и автоматически запрашивается заново — сообщение не теряется.
- **Честное подтверждение**: отправитель получает подтверждение доставки только после полной проверки файла на телефоне получателя.

Уже полученные с ошибкой голосовые нужно отправить заново: после обновления они придут как обычно.
