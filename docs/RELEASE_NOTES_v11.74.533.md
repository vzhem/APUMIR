# v11.74.533 — звук и вибрация теперь в настройках приложения

Собрано из ветки `arena/b19361a0-apumir`.

- **Настройка нашлась там, где её искали.** В 532 звук и вибрация работали, но
  выбора в приложении не было: всё решалось каналами в системных настройках
  Android. Владелец туда не пошёл и справедливо написал «в настройках не нашёл
  функцию со звуком и вибрацией». Теперь в «Настройки → Уведомления», сразу под
  «Фонариком», есть карточка **«Звук и вибрация»**.
- **По разделам и целиком.** В карточке четыре строки: **всё приложение**,
  **личные сообщения**, **группы**, **каналы**. У каждой — два независимых
  переключателя, «Звук» и «Вибрация»: кому-то нужен только звук без тряски,
  кому-то наоборот. Общий выключатель приложения только запрещает: если звук
  выключен «для всего», раздел не вернёт его обратно.
- **Почему это не одна галочка.** На Android 8+ звук и вибрация принадлежат
  каналу уведомлений, а настройки уже созданного канала код изменить не может.
  Поэтому на каждый раздел заводится четыре канала — «звук и вибрация», «только
  звук», «только вибрация», «без звука» (12 каналов). В момент показа
  `NotificationHelper` выбирает канал по разделу и по выбору человека, так что
  переключение действует сразу, без перезапуска. Имена каналов в системе
  читаются словами: «Личные сообщения — только вибрация».
- **Тихое сообщение молчит всегда.** Служебный префикс тихого сообщения
  по-прежнему уводит в тихий профиль, что бы ни стояло в настройках.
- **Режим телефона не отменяется.** «Звук» звучит только на громкой, «Вибрация»
  вибрирует только в режиме вибрации: это правило системы, приложение его не
  обходит.
- Каналы 532 (`apu_messages_v2`, `apu_messages_quiet_v1`) остаются: удалять
  системную настройку, которую человек уже трогал, нельзя.

**Как проверить:** «Настройки» → «Уведомления» → карточка «Звук и вибрация».
Выключить «Вибрация» у личных сообщений — личное приходит без тряски, группа
по-прежнему вибрирует. Выключить «Звук» у «Всё приложение» — тихо везде.
