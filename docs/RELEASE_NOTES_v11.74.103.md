# APU v11.74.103 — пустые стикеры: автоподгрузка, кнопка «обновить», запрет пустышек

## Что изменилось (раунд 206)

Владелец (скрины: панель с пустыми плитками и чат, где уехал
«Стикер.webm 202,7 КБ» без картинки): «Отправил стикер который не
прорисован в каталоге. Он в чате тоже не прорисовался. Нужно если они
пустые то они автоматически подгрузились из роя. А если из роя не
могут то нужно рядом поставить пузырь со стрелочкой по кругу
означающая обновить и при нажатии на неё то подгружается со внешнего
ресурса.»

### Автоподгрузка при открытии панели

StickerSection: LaunchedEffect собирает плитки «Недавних» и «Моих» без
файла, находит их записи в каталоге «Из сети» и тихо докачивает
(по одной с паузой 600 мс, до 8 за круг; повторные призывы
дедуплицируются 2-минутной паузой want-запросов). Приехали - плитка
оживает (thumbTick/refresh).

### Пузырь «обновить» ↻

На пустой плитке - золотой кружок «↻»: force=true (сброс паузы) и
maxTargets=12 - просьба ВСЕМ держателям из каталога, не только трём
лучшим (StickerLibrary.requestSticker + force/maxTargets). Статус
«Просим у всех держателей сети…». Если держателей нет - «×» (файл
физически неоткуда взять: стикеры E2E-приватные, на сервере не
хранятся).

### Запрет «пустышек»

sendSticker (личка и группы): файла нет → не отправлять визитку, а
autoFetch + pendingSwarmStickerSha («Стикер подгружается из сети -
сразу отправим»; по приезде уйдёт сам). Нет в каталоге - честное
«Файл стикера пропал с телефона - докачать его неоткуда». Именно так
уезжала битая карточка «Ждём получателя онлайн» навсегда.
