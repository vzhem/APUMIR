# APU v11.74.251 — Контакты, профиль, QR и уведомления на английском

Экраны добавления и переименования контакта, поделиться профилем, сканера QR-кода и отключения уведомлений теперь выводят текст на выбранном языке.

- Добавление контакта: ссылка-приглашение, поиск по @никнейму, сканирование QR-кода.
- Поделиться профилем: ссылки для добавления, короткая и Telegram-ссылки, копирование.
- Переименование контакта: данные контакта, имя и никнейм.
- QR-код: сканирование, разрешение камеры, свой QR-код, приглашение в APU.
- Отключение уведомлений: срок, ручное и автоматическое включение.
