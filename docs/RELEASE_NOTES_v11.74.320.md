# Темы группы теперь вверху

- Прокручиваемая полоса тем под шапкой группы.
- Переписка и поле ввода на всю ширину, без боковой колонки.
- Названия тем, непрочитанные сообщения и выделение выбранной темы.
- Кнопка «Все» открывает список тем; создание доступно администраторам.
