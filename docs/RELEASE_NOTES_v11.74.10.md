# APU v11.74.10 — непрочитанные комментарии на каждом посте

## Главное

Значок непрочитанных (золотой кружок с числом — такой же, как на канале в
списке) появился **на каждом посте, у кнопки комментариев**: видно, сколько
нового именно в этом посте, не открывая его.

- Пришли комментарии к посту → на посте загорелось «3», открыли комментарии →
  значок погас (и канал в списке перестал их считать).
- Значок на канале по-прежнему = сумма по всем постам.
- Если пост сам новый и его комментарии ещё не открывали — значок покажет «1»
  (непрочитан сам пост): заодно служит меткой «пост новенький».
- В больших каналах (рой через владельца) считается то, что дошло до вашего
  телефона.

Всё уже существовавшей механикой: счётчик ведёт база на каждом чужом
сообщении темы, сбрасывает экран комментариев при чтении. Нового сетевого
трафика ноль.

## Прочее

Без изменений сервера, шифрования и доставки.
