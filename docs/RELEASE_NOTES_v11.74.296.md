# APU v11.74.296 — Новый премиальный стиль во всём приложении

Все разделы приложения оформлены в едином премиальном стиле: кнопки, поля, диалоги и индикаторы стали объёмнее и отзывчивее.

- Кнопки действий объёмные: подъём, блеск, нажатие с мягким сжатием и светлый переллив при нажатии.
- Фильтры, переключатели и диалоги выглядят одинаково во всех разделах: размер шрифта, перевод, язык, напоминания о поддержке.
- Индикаторы загрузки в золотом стиле: крутятся только пока идёт загрузка.
- Поля поиска и ввода в одном виде, разделители — тонкая золотая нить.
- «Написать разработчику» в настройках: письмо с логами и скриншотами, которые вы выбираете сами.
- Свайп по сообщению для ответа работает по всей ширине строки.
