# APU v11.74.239 — Подписи чатов, групп и администрирования на английском

На английском выводятся подписи с именами и числами в списке чатов, в группах и в настройках администрирования.

- Подпись «Черновик» в списке чатов.
- Подписи публичной и частной группы с числом участников.
- Счётчик выбранных сообщений в группе.
- Подпись «Ответ» с именем автора в группе.
- Подсказка для ввода подтверждения в администрировании группы.
