# APU v11.74.217 — Согласие на загрузку языкового пакета

- При включении «Переводить входящие сообщения» теперь показывается окно: языковые пакеты Google, около 30 МБ на каждый язык, скачиваются один раз, текст сообщений на сервер не отправляется.
