# APU v11.74.81 — аудит-5: кэш времени в интерфейсе

## Что изменилось (раунд 184)

Находка: в самых горячих компонентах форматтер времени создавался
ЗАНОВО при каждой перерисовке каждой строки:
- MessageBubble.formatMessageTime: SimpleDateFormat + 2 Calendar;
- ContactCard.formatChatTime (строки чатов и контактов);
- ChatListScreen.formatGroupTime;
- GroupChatScreen.topicTimeLabel.

SimpleDateFormat - одна из самых дорогих операций Java-текста
(локаль, компиляция шаблона). При открытом чате с десятками сообщений
и частых перерисовках (набор, реакции, статусы) - постоянная работа
ЦП и мусор для GC.

Фикс: remember(timestamp, часовой маркер) на месте вызова - строка
считается один раз на сообщение; часовой маркер гарантирует, что
«Вчера» после полуночи сменится датой не позже чем через час.

Проверено аккуратно: каналы уже были с remember; списки чатов и
разделы собираются в фоне (buildState на Dispatchers.Default) -
не тронуто; ключи у лент есть. Поведение не изменено.
