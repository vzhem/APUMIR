# Управление помощью другим телефонам

- В настройках раздачи можно отключить временную пересылку чужих пакетов, не отключая свою переписку.
- Обычный и экономный режимы снижают нагрузку онлайн-помощи на мобильной сети и при низком заряде.
- Для входящих данных владельца оставлен запас; уже принятые пакеты могут завершить передачу после отключения помощи.
- Исправлены английские названия режимов раздачи.

Настройка не меняет правила хранения чужих файлов. Доступность связи зависит от сети.
