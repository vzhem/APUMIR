# APU v11.74.298 — Цвет подложки и новая статистика

Подложку теперь можно окрасить в один из 10 цветов, а статистика группы оформлена в новом стиле.

- Настройки → Обои: выбор цвета подложки, 10 вариантов: классическая, мята, лаванда, персик, небо, роза, песок, оливка, графит, океан. Для дневной и ночной темы свой оттенок.
- Своя картинка из галереи важнее цвета подложки.
- Статистика группы: новые карточки, график и рейтинг в премиальном стиле.
- Окно обновления прокручивается целиком: кнопки видны в альбомной ориентации и при крупном шрифте.
