# APU v11.49.0

Двадцать анимированных реакций, понятное описание рангов и подложка, которая больше не пропадает при прокрутке.

- Реакций теперь двадцать, все доброжелательные: они появляются волной, а выбранная мягко пульсирует.
- Значок реакции под сообщением оживает, когда её поставили или сняли.
- Раздел «Ранги и возможности» описывает именно ваш ранг и показывает, сколько приглашений до следующего; ранг по промокоду работает наравне с заработанным.
- Из описания убраны технические английские слова.
- Фоновая картинка больше не пропадает при прокрутке списков, а полоска состояния соединения перестала закрывать её сплошной заливкой.
