# APU MIR v11.74.385

## Живой текст звонка — по кнопке

Во время разговора появилась кнопка «Текст звонка» (во втором ряду кнопок, рядом с показом экрана).

- Нажмите её — и речь начнёт появляться текстом прямо на экране звонка: ваши фразы подписаны «Вы», фразы собеседника — «Собеседник».
- Незаконченная фраза дописывается на глазах и становится обычной строкой, когда человек договорил.
- Всё распознаётся на самом телефоне параллельно разговору, звук никуда не отправляется.
- Если модель распознавания ещё не скачана (первый перевод голосового её уже поставил — тогда ничего качать не надо), при первом включении она скачается один раз.
- Кнопка нажимается ещё раз — текст выключается. По умолчанию в звонке текст выключен: включается только по требованию.
