# Release v11.74.404 — Эмодзи-статус у профиля

## Что нового

- **Эмодзи-статус рядом с профилем (виден всем).** В своём профиле
  (Настройки → раздел профиля) под именем появилась плашка «Эмодзи-статус»:
  нажмите и выберите один значок из палитры — например 🌙, 🎧, 🚀, ❤️.
  Выбранный значок стоит рядом с вашим именем у всех, кто вас видит.
- **Где виден статус:** в карточке профиля собеседника (открывается по
  нажатию на имя) и в списке контактов — справа от имени, рядом с VIP-знаком.
- **Как распространяется:** статус объявляется по сети так же, как имя и
  аватар: уходит прямым контактам, а те передают его дальше (с лимитом
  прыжков), поэтому его видят и не-контакты. Также статус передаётся в отвеете
  на запрос «кто ты» (whois), поэтому появляется и у тех, кто вас встретил
  впервые.
- **Смена и уборка:** смена статуса мгновенно публикует новый значок; кнопка
  «Убрать статус» публикует пустой статус — у всех значок исчезает.
  Побеждает самое свежее объявление владельца (по времени), старые пакеты
  не затирают новые.
- Совместимость: телефоны со старой версией пакета `emst` просто игнорируют —
  ничего не ломается.

## Проверка на телефоне

1. Обновите оба телефона до v11.74.404.
2. На первом: Настройки → профиль → «Поставить эмодзи-статус» → выберите,
   например, 🚀.
3. На втором откройте список контактов и карточку профиля первого: рядом с
   именем должен стоять 🚀.
4. На первом смените статус на 🌙, затем нажмите «Убрать статус»: на втором
   значок должен смениться, а после уборки — исчезнуть.
