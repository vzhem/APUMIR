Улучшены восстановление связи с друзьями и проверка обновлений APU.

- При запуске сохраняется прежний адрес профиля; при расхождении сохранённых данных новый адрес не создаётся автоматически.
- Приложение чаще пытается восстановить связь с сохранёнными контактами, в том числе по прямому соединению.
- Индикатор «в сети» учитывает свежесть сведений о собеседнике.
- После перезапуска или обновления служба доставки точнее определяет, когда ей нужно проснуться.
- Перед загрузкой обновления заново проверяется актуальная версия; доступны основной и резервные источники.

**Известные ограничения:** очистка переписки у собеседника остаётся ограниченной; связь и установка обновления на физических устройствах ещё не проверены.
