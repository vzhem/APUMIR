APU v11.35.0

Появился раздел «Избранное» — личное хранилище для всего нужного.

- «Избранное» открывается из меню в правом верхнем углу главного экрана.
- Из личного чата можно переслать себе любой файл, фото, видео, документ или текст сообщения.
- Из группы сообщение сохраняется долгим нажатием, из канала — кнопкой «В избранное» под постом.
- Внутри раздела можно оставить и свою заметку кнопкой «+».
- У сохранённого файла есть «Сохранить в телефон» и «Поделиться».

Известное ограничение: сохранённый файл — это ссылка на файл из чата, копия не создаётся; если удалить переписку с файлом, запись в избранном останется без содержимого.
