# APU v11.74.241 — Сообщения резервных копий на английском

Сообщения экранов резервной копии профиля и восстановления личности теперь выводятся на выбранном языке. Это первый батч, где переведены сообщения из ViewModel: они берут текст через контекст приложения.

- Ошибки пароля, проверки файла копии и повреждённых копий.
- Статусы сохранения, открытия и автообновления копии.
- Сообщения восстановления личности: неверный никнейм или пароль, нет связи с сервером, копия сохранена на телефоне.
- Подсказка про хранилище без постоянного доступа к файлу.
