# APU v11.74.26 — каталог с миниатюрами; живой поиск; надёжные ссылки

## По вашим замечаниям

1. **Миниатюры чужих гифок в каталоге.** Картинки гифок «у других
   телефонов» теперь подгружаются с хранителей автоматически
   (крошечные копии ~96px, кэшируются). Каталог при открытии сразу
   показывает тренды — выбирать можно сразу.

2. **«мой» и «у N» убраны** — осталась только синяя точка «уже в
   нашей сети».

3. **Живой поиск** — начинается с первой буквы, не нужно жать на
   лупу.

4. **Выбор гифки закрывает окно** и показывает чат, куда она встала.

5. **Гифка из сети теперь доезжает до получателя.** Ссылка — сама
   часть сообщения: карточка у получателя появляется в любом случае
   (от лица отправителя), байты его телефон тихо забирает у
   хранителей — карточка оживает у обоих. Никаких «непонятных ссылок»
   в чате.
