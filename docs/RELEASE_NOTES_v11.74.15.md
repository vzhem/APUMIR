# APU v11.74.15 — GIF: личные чаты, чистые пузыри, реакции

## Главное (по замечаниям владельца после v11.74.14)

1. **Кнопка GIF теперь и в личных чатах** — тот же каталог: поиск,
   выбор, гифка уезжает собеседнику защищённой передачей файлов.
2. **Гифка в группе/канале — только картинка.** Имя файла и размер
   показываются, только пока гифка ещё едет; когда картинка на месте —
   она и есть сообщение (никаких «📎 gif_xxx.gif (1,2 МБ)»).
3. **Реакция ставится и на саму гифку** — долгое нажатие на картинке
   открывает меню, как на любом сообщении (раньше область карточки
   «проглатывала» жест).
4. В личном чате гифка тоже приходит анимацией; имя/размер скрываются
   сразу, как картинка доехала.

## Прочее

Без изменений сервера и шифрования.
