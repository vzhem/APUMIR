# APU v11.74.224 — Знакомство с приложением на английском

Первые экраны после установки (создание профиля, вход в прежний профиль, добавление контакта) теперь выводятся на выбранном языке.

- Переведены выбор «Новый профиль» или «Я уже зарегистрирован», поля имени, никнейма и пароля, подсказки и проверки.
- Переведены шаги создания ключей и экран «Профиль создан».
- Переведены подсказки про QR-код, ссылку от друга и кнопку «Начать общение».
- Тексты с подставляемым минимальным числом знаков пока на русском языке.
