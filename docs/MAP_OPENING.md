# Открытие геопозиций во внешних картах

## Запрос владельца

Геопозицию можно открыть в Яндекс.Картах либо выбрать приложение. Приложение
по умолчанию настраивается отдельно для этого устройства.

## Где находится

**Настройки → Чаты → Открытие геопозиций**:

- **Спрашивать каждый раз** — начальный вариант; системный выбор доступных карт.
- **Яндекс.Карты** — сразу установленное приложение `ru.yandex.yandexmaps`.
- **Google Maps** — сразу установленное приложение `com.google.android.apps.maps`.
- **2ГИС** — сразу установленное приложение `ru.dublgis.dgismobile`.
- **Веб-карта в браузере** — Яндекс.Карты по HTTPS, без требования устанавливать
  отдельное приложение карт.

Выбор сохраняется локально и восстанавливается при запуске. Сброс настроек чатов
возвращает «Спрашивать каждый раз». Переписка, контакты и ключи не меняются.

## Два места открытия

1. Полученная карточка геопозиции в личном чате, группе или канале:
   **Открыть в картах**.
2. Экран **Отправить геопозицию**: **Открыть в картах** открывает текущую точку
   под центральной меткой. Это не отправляет сообщение. Отправка остаётся отдельной
   кнопкой; подпись и выбранная точка сохраняются при возвращении из внешнего приложения.

Встроенная карта выбора точки по-прежнему использует OpenStreetMap. Новый SDK,
ключи Яндекс.MapKit и замена поставщика тайлов не добавляются: внешнее открытие —
отдельное действие, а не скрытая передача данных при показе экрана.

## Координаты и приватность

- Внешнее приложение получает координаты только после явного нажатия кнопки.
- Само появление карточки, выбор приложения в настройках и проверка установленности
  не запускают карты и не передают реальную точку.
- Подпись сообщения, точность GPS, ключи и история переписки во внешний intent не входят.
- Если выбранное приложение удалено/отключено, APU показывает понятное сообщение
  и предлагает выбрать другое приложение либо браузер. Молчаливой подмены нет.
- Формат сообщения `APULOC1` и ссылка для старых клиентов не изменены.
- На Android 11+ видимость пакетов ограничена картами и браузерами в `<queries>`;
  разрешение `QUERY_ALL_PACKAGES` не используется.

Для `geo:` порядок — широта, долгота. Для точки Яндекс/2ГИС — долгота, широта.
Форматирование чисел не зависит от локали телефона. Неправильные/неконечные
координаты не превращаются во внешнюю ссылку.

## Проверки

- JVM: `MapOpeningPolicyTest` — варианты, пакеты, оба порядка координат, отрицательные
  координаты, границы, локаль, отказ от некорректных значений.
- Контракт: `scripts/ci/check-map-opening.py` — общее действие для карточки и выбора
  точки, отсутствие запуска при композиции, локальная настройка/сброс, видимость
  пакетов, RU/EN, явный запасной выбор без скрытой подмены приложения.
- На телефоне ещё нужно проверить: выбор Яндекс по умолчанию; удаление/отключение
  выбранного приложения; «Спрашивать каждый раз»; Google/2ГИС при наличии; браузер;
  возврат в незавершённую отправку; перезапуск APU; сброс настроек чатов; RU/EN.
