# APU v11.74.219 — Управление группами на английском

Экран администрирования группы и каналов теперь выводится на выбранном языке.

- Переведены названия, описание, аватар, публичность и темы группы.
- Переведены режим медленной отправки, выход из группы и удаление с подтверждениями.
- Переведены роли, передача владения и список администраторов.
- Переведены ссылки-приглашения, заявки и разрешения участников.
- Тексты с подставляемыми значениями (сроки, количество дней) и часть вкладок пока на русском языке.
