# APU v11.74.188 — кнопка «Применить» теперь тоже видна над клавиатурой

Маленькое исправление к v11.74.187 по вашему скриншоту: поле промокода над
клавиатурой было видно, а кнопка «Применить» оставалась под ней.

## Что изменилось

**Поле и кнопка теперь поднимаются вместе.** Раньше список подводил наверх только
само поле, поэтому кнопка под ним оставалась закрытой клавиатурой. Теперь поле и
кнопка — один блок: при нажатии на поле список поднимает его целиком, и кнопка
«Применить» видна вместе с полем.

**Подвод делается дважды.** Клавиатура появляется с анимацией, поэтому второго
подвода (через мгновение после первого) хватает, чтобы блок встал на место — без
прыжков и без «мигнуло и уехало».

## Что не менялось

Промокод по-прежнему проверяется на самом телефоне, повторно на одном устройстве
код не срабатывает, а ранг от промокода действует наравне с заработанным. Ничего
кроме поведения клавиатуры в этом выпуске не менялось.

## Установка

Настройки → «Проверить новую версию» → v11.74.188. Выпуск для тех, кто уже на
v11.74.187.
