# APU v11.74.346 — файлы и фото можно сохранить на телефон

Любой файл или фото из переписки сохраняется на телефон из меню: личный чат, канал, группа, тема и группа без тем.

- В меню сообщения появился пункт «Сохранить в папку» — и у фото, и у документов.
- То же в группах, темах и каналах, в том числе для файла, который отправили вы.
- Откроется системное окно: выберите папку на телефоне.

**Ограничение:** пункт виден, когда файл уже полностью на этом телефоне.

## English

**APU v11.74.346 — save files and photos to the phone**

Any file or photo from a chat can be saved to the phone from the menu: private chat, channel, group, topic, and a group without topics.

- The message menu now has “Save to folder” — for photos and for documents.
- The same in groups, topics, and channels, including a file you sent yourself.
- The system picker opens so you can choose a folder on the phone.

**Limitation:** the item appears when the file is already fully on this phone.
