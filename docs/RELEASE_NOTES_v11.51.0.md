# APU v11.51.0

Реакция теперь взлетает точно от того места, где её поставили, а группы открываются без зависаний.

- Полёт реакции стартует ровно от нажатого значка и длится дольше — раньше он срывался в верхнюю часть экрана и слишком быстро исчезал.
- Убрано зависание при входе в группу и при возврате назад.
- Значки групп в боковой колонке готовятся заранее и больше не задерживают открытие экрана.
- Списки групп обновляются заметно легче для устройства.
