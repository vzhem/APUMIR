# APU — запуск следующего ИИ-чата

**Этот документ не является готовым prompt.** Для актуального контекста откройте
`docs/HANDOFF_NEXT_AI.md` первым. Там зафиксированы стабильный релиз v11.74.206,
различие `main` и Arena-ветки, незавершённые локальные APK-speed изменения, проверки,
ограничения и безопасный план продолжения.

`docs/START_HERE.md` — навигация и историческая хронология релизов. Старые срезы в
ней могут содержать бывший Latest, старую ветку и уже закрытые задачи; не трактовать
их как текущий статус. Перед любым публичным релизом обязательно прочитать
`docs/RELEASE_PUBLICATION_POLICY.md`.
