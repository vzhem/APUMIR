# APU v11.74.226 — Узлы сети на английском

Экран «Узлы сети» (рейтинг телефонов, через которые идут данные) теперь выводится на выбранном языке.

- Переведены заголовки, пояснение о том, как считается рейтинг узла, и подсказка про пустой список.
- Переведены подписи показателей: в сети, скорость обмена, доставка, прямая связь, место под пересылку.
- Переведены значения «нет данных», «есть», «только через других», «не сообщал».
- Тексты со скоростью, баллами и уровнем узла пока на русском языке.
