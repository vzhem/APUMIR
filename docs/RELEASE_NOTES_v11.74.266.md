# APU v11.74.266 — Индикатор резервной копии на английском

Исправлено: при английском языке индикатор «Собираем копию…» и «Открываем копию…» в резервной копии профиля не появлялся, потому что экран определял действие по русскому тексту. Теперь действие передаётся кодом, и индикатор работает на любом языке.
