# APU v11.74.74 — стабильное имя в профиле

## Что изменилось

Владелец: «быстро переходишь на вкладку профиля - показывает анонимус,
а потом подгружает реальное имя. должно быть стабильное имя».

Причина: SettingsUiState.displayName по умолчанию «Anonymous», имя
читалось в фоновой корутине loadSettings (IO: ключ ядра, ссылка, пиры,
IP, версии). Фикс: в init БЕЗ корутины читаем одну строку
p2p_prefs/display_name (мгновенно, prefs уже в памяти) и кладём в
state до первого кадра. Нагрузки не добавляет: одно чтение кэша
настроек; тяжёлая часть осталась в фоне.
