# APU MIR v11.74.382

## Дата рождения — только в прошлом

Будущую дату рождения поставить больше нельзя.

- Календарь при выборе даты рождения не даёт уйти дальше сегодняшнего дня.
- Если дата всё же окажется будущей (например, осталась от старой версии), приложение покажет подсказку и не даст сохранить её, пока не выберете дату не позже сегодняшней.
- Число и месяц при этом не пропадают — отбрасывается только невозможный год.
