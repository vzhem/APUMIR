# Фон профиля

## Что это

Локальное оформление экрана собственного профиля: пользователь выбирает изображение,
и оно становится подложкой профиля и экрана «Поделиться профилем». Если своего фона нет,
показывается стандартная подложка APU / общие обои чатов.

Фон профиля **не отправляется собеседникам**, не входит в аватар, групповые обои,
зеркало профиля и резервную копию профиля. Это настройка только этого устройства.

## Выбор и сброс

- Профиль → карточка «Фон профиля» → «Выбрать изображение».
- Используется системный выбор фото (`PickVisualMedia`), без запроса доступа ко всей галерее.
- Диалог показывает предпросмотр, состояние подготовки, ошибку или подтверждение сохранения.
- «Вернуть стандартный фон» удаляет только управляемые файлы фона профиля.
- Сброс настроек «Оформление» также возвращает стандартный фон профиля.

## Хранение и ограничения

- Исходник копируется во временный файл с потоковым лимитом 24 МиБ.
- Размеры исходника проверяются до декодирования; стороны не больше 20 000 px.
- Декодирование использует степенной `inSampleSize`, поворот EXIF учитывается.
- Готовый JPEG хранится в приватной папке `filesDir/profile-background`.
- Лестница сжатия: стороны 1600/1280/1024/800, качество 85/72/60; итог не больше 512 КиБ.
- Публикация атомарная: временный файл `.jpg.tmp` синхронизируется и переименовывается,
  затем сохраняется путь в preferences. Старые управляемые файлы убираются.
- Имена файлов строго ограничены UUID-шаблоном; символические ссылки и чужие файлы не трогаются.
- Отображение декодирует файл вне главного потока и накладывает лёгкую вуаль темы для читаемости.

## Проверка

- JVM: `ProfileBackgroundPolicyTest` — лимиты, масштабирование, sampling, имена файлов.
- Контракт: `scripts/ci/check-profile-background.py` — локальность, потоковый лимит,
  атомарная запись, wiring экранов, сброс, RU/EN строки.
- На устройствах ещё нужны: выбор фото, поворот EXIF, перезапуск, день/ночь,
  крупный шрифт, отказ/ошибка выбора, сброс оформления.
