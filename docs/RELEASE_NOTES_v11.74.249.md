# APU v11.74.249 — Остаток сообщений чата и настроек на английском

Последние короткие сообщения из моделей чата и настроек, которые раньше оставались на русском, теперь выводятся на выбранном языке.

- Чат: нет связи с сервисом APU, не удалось войти по ссылке, сервер перегружен для кнопки «Ещё» в гифках.
- Настройки: сообщение о том, что копии на сервере ещё нет.
