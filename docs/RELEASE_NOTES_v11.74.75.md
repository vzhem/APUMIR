## Что изменилось

Владелец: «отправитель отправил гифку - не ждал собеседника. приложение
само доставит получателю когда он появится в сети. если сама не может -
через рой».

   «Собеседник недоступен». Гифка-ссылка ВСЕГДА попадает в чат:
   - отправилось -> статус LOCAL_FILE (как раньше);
   - нет -> QUEUED_OFFLINE (телефонная очередь).
2. Доставка очереди - СУЩЕСТВУЮЩИЙ конвейер (ничего нового):
   retryPendingMessagesForPeer/FULL SYNC по presence (CoreServerService
   peer_discovered), getUnconfirmedOutgoingMessages включает
   QUEUED_OFFLINE; получатель байты добирает из роя у хранителей
   (ensureGifRef). Статус в панели: «Гифка будет доставлена, когда
   собеседник появится в сети».
3. Аудит (шаг 1, только безопасное): публичный IP в профиле - по кэшу
   10 минут (api.ipify.org больше не дёргается при каждом открытии
   вкладки).
