# APU v11.74.237 — Подсказки чата, QR, аватара и никнейма на английском

На английском теперь выводятся длинные подсказки в чате, на экране QR-кода, при обрезке аватара, в окне гифок и при занятом никнейме.

- Подсказки о том, что сообщения собеседника не открываются из-за старой копии ключа.
- Подсказка о собственном узле и синхронизации устройств одного аккаунта.
- Подсказка на экране QR-кода, пока ключи ещё создаются.
- Подсказка по перемещению фото при обрезке аватара.
- Пояснение синей точки у гифок в нашей сети.
- Сообщение о занятом никнейме с предложением выбрать новый.
