# APU v11.74.118 — «Действия с сообщением» по-человечески

## Что изменилось (раунд 222)

Владелец: «в личных сообщениях нажал на три точки у гифки, перешёл в
меню, а там гифка называется цифрами буквами. Нужно сделать чтобы было
человеко понятно».

Причина: окно «Действия с сообщением» показывает превью содержимого
сообщения как есть. У гифки-ссылки содержимое — служебный маркер
`APUGIFREF1|<sha256>` (р210), он и попадал в превью.

## Исправление

Превью строится по-человечески:
- гифка-ссылка → слово **«Гифка»**;
- файл/стикер (маркер APUFILE1) → привычная подпись
  **«📎 имя (размер)»**, как на карточке файла;
- обычный текст — как был.

«Копировать всё» и «Выделить часть текста» не менялись: копирование
намеренно отдаёт содержимое целиком (оно нужно машинам — например,
переслать ссылку в другое приложение).

## Механика

- ChatDetailScreen.kt, окно showCopyDialog: previewText теперь
  stripHeader → isGifRef? «Гифка» : GroupFileMarker.parse → caption
  (📎 имя (размер)) : сырой текст. Diff +12/−1, один файл.
