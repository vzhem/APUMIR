# APU v11.74.212 — Перевод входящих сообщений

Новая функция: входящие сообщения на другом языке можно переводить на язык приложения.

- В настройках включается «Переводить входящие сообщения».
- Перевод выполняется на телефоне; текст переписки не отправляется на сервер.
- Под переведённым сообщением есть «Показать оригинал».

Первый перевод для каждого языка загружает языковой пакет (около 30 МБ).
