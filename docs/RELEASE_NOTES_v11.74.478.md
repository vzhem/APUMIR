APU 11.74.478

Меньше лишних копий APK и более надёжный выбор источника обновления.

- Приложение скачивает APK с сайта APU только если версия и SHA-256 в sidecar совпадают с последним релизом.
- Если копия устарела, не подтверждена или сайт недоступен, обновление скачивается через резервный канал.
- После установки автоматически удаляются лишние копии уже установленного APK; актуальная раздача и более новое ожидающее обновление сохраняются.
- Переписки, контакты и ключи остаются нетронутыми.

Примечание: для прямой загрузки с сайта должна быть опубликована актуальная версия APK и сопроводительная информация о версии и контрольной сумме. Пока сайт не обновлён, приложение использует резервный канал.
