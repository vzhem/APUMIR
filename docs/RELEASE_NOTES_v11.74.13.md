# APU v11.74.13 — тап по уведомлению ведёт к сообщению

## Главное

Нажатие на всплывающее уведомление теперь открывает **то место, где
написано сообщение**, а не просто приложение:

- личное сообщение → сразу этот чат;
- сообщение в группе → сразу та тема, где написано;
- комментарий/пост в канале → сразу этот пост с комментариями.

Уведомление после тапа само убирается из шторы. Работает и когда
приложение закрыто (откроется и доведёт), и когда свёрнуто.

## Прочее

Без изменений сервера, шифрования и доставки.
