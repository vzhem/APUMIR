# APU v11.70.6

Посты каналов теперь раздают друг другу сами подписчики.

- Вступили в канал, а его владелец не в сети - последние посты всё равно придут: их дошлёт любой подписчик, у которого они есть. Раньше посты приходили только от владельца.
- Каждый пост подписан ключом автора, поэтому пересланный другим подписчиком пост нельзя подменить: телефон принимает только то, что сходится с подписью владельца или администратора канала.
- Просьба «дослать посты» уходит сразу нескольким соседям по каналу, и нагрузка на телефон владельца падает.

Обновление получают все: окно с предложением обновиться появится при запуске.
