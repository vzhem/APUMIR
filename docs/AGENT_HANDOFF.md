## Причина расхождения после v11.74.329

`v11.74.329` (`198e1da`) продолжал стабильную линию релизов. Следующий коммит `v11.74.330` (`3d37de6`) ошибочно ответвился напрямую от `4e5624c` — `main` на стабильном v11.74.206. У веток был общий предок v11.74.206; линия v329 содержала ещё 176 коммитов и 276 изменённых путей, включая интерфейс и ресурсы русского/английского языков. Поэтому .330–.336 собирались без изменений .207–.329, что и объясняет исчезновение доработок в APK, несмотря на сохранённые теги.

Исправление: в эту Arena-ветку влит полный предок `v11.74.329`, затем сохранены доработки .330–.336 (content-addressed chunks, проверки и CI-фиксы). Конфликты StoryStore/StoryPhotoParts разрешены в пользу совместимой интеграции новых проверок с API и поведением историй из .329; тесты покрывают и новый, и старый формат фото-пакетов. Русские и английские UI-ресурсы и код между .207 и .329 теперь снова входят в дерево ветки.

Опубликованный `v11.74.336` по-прежнему указывает на старое дерево до восстановления; теги/ассеты .335 и .336 не перемещались. Владелец запросил новый публичный релиз для всех. Подготовлен bilingual draft `docs/RELEASE_NOTES_v11.74.337.md`, пока только в рабочем дереве и не запушен: требуется показать и утвердить точный публичный текст по `RELEASE_PUBLICATION_POLICY.md`. Тег/release .337 ещё не созданы, Latest остаётся .336. После утверждения: закоммитить/запушить заметки, запустить tag workflow для скрытого draft, опубликовать как stable Latest только после зелёной сборки/тестов и проверки assets; старые теги не перемещать.

На объединённой ветке нет нового CI-run. GitHub workflow dispatch через `gh` ранее возвращал 403; не повторять тот же вызов. В sandbox отсутствуют Java/Gradle и Rust/Cargo, поэтому локальная Android/JVM/native-сборка невозможна. До merge прошли `git diff --check`, unresolved-symbol scan (524 файла), Python source-contract suites и RU/EN XML-key parity (1524 strings, 2 arrays, 3 plurals с каждой стороны). `check-chat-style.py` имеет 4 известных падения; те же падения воспроизводятся на чистом архиве `v11.74.329`, это не регресс merge.
