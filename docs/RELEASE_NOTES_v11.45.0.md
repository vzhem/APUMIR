# APU v11.45.0

Обновление про ранг и приглашения: значок ранга теперь меняется сразу, а группу можно предложить друзьям в пару касаний.

- После ввода промокода надпись ранга на главном экране обновляется сразу, без перезапуска приложения.
- В меню группы на главном экране появился пункт «Пригласить в группу» (для каналов — «Пригласить в канал»).
- Приглашение отправляется одной ссылкой: у кого APU уже установлен — сразу откроет группу, остальным ссылка предложит установить приложение.
- Мелкие улучшения стабильности интерфейса.
