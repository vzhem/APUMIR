# APU v11.73.0

Группы и каналы больше не остаются без владельца: права можно передать дальше, а если владелец удалился из сети — забрать.

- Владелец может передать группу или канал администратору — кнопка «Передать владение» в админке, с подтверждением.
- Если владелец давно не выходил на связь (90 дней), любой администратор группы может стать владельцем.
- Если администраторов нет, то же могут участники — но позже, через 180 дней молчания владельца.
- При передаче и наследовании бывший владелец остаётся администратором со всеми правами: если он вернётся, его ничто не ограничивает.
- Всё остальное — как в v11.72.0.

Обновление получают все: окно с предложением обновиться появится при запуске.
