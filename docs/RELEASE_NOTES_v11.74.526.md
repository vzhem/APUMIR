# v11.74.526 — приложение больше не падает, когда система поднимает его в фоне

Собрано из `f9f5754`.

Устранена причина падения приложения при фоновом запуске: модуль распознавания
больше не запускается в процессе, где ещё не было экрана.

- Падение на инициализации ML Kit больше не обрывает приём сообщений и сигналов.
- В процессе без экрана перевод, фильтры лица и замена фона просто не
  включаются — это заметно только там, где их и не показывают.
- Строка `служба=` в «Логах» больше не объявляет службу недоступной по одной
  проверке: состояние берётся из настоящих ответов службы.

**Как проверить:** обычная работа приложения; в «Логах» в разделе `[push]` строка
`последняя_ошибка` должна оставаться `-`, а `reason=crash` — не появляться.
