# Вспышка фонарика при сигнале SOS и входящих сообщениях

Световой сигнал на телефоне получателя дополняет звук и вибрацию: если вокруг
шумно или экран лежит вниз, мигание вспышки камеры сразу привлекает внимание.

## Как устроено для человека

В разделе **«Настройки → Уведомления»** расположена карточка вспышки фонарика с
двумя независимыми настройками этого устройства:

1. **Фонарик при SOS из группы** — включено по умолчанию.
   - Когда участник группы отправляет тревожный сигнал SOS, у получателей
     вспышка отбивает рисунок Морзе `··· −−− ···` (~3,5 с), даже если сама
     группа поставлена на паузу звука.
   - Получатель может в любой момент выключить или снова включить эту функцию
     переключателем.
   - Одно нажатие кнопки SOS в группе шлёт пачку из 3–5 сообщений подряд: они
     склеиваются в одну непрерывную серию вспышек и не обрывают друг друга.
2. **Фонарик для сообщений** — по умолчанию «Выключено».
   - Варианты выбора:
     - **Выключено** — обычные сообщения вспышку не трогают;
     - **Все сообщения** — личные чаты, группы и каналы;
     - **Только личные чаты**;
     - **Только группы**;
     - **Только каналы**.
   - На чаты/разделы без звука и на тихие сообщения вспышка для обычных
     сообщений не срабатывает.
   - Обычное сообщение даёт короткую двойную вспышку (~0,4 с). Если приходит
     тревога SOS, она имеет приоритет над обычной вспышкой.

Сброс категории «Уведомления» в сбросе настроек возвращает значения по
умолчанию (`SOS = включено`, `Сообщения = выключено`).

## Технические детали

- `data/notification/FlashlightAlertPolicy.kt` — чистые правила без Android SDK
  (режимы, классификация раздела, приоритет SOS, склейка пачки SOS и защита от
  стробоскопа при потоке сообщений).
- `data/notification/FlashlightAlertStore.kt` — локальное хранилище
  `SharedPreferences` (`notification_flashlight`) с синхронной записью.
- `service/FlashlightBlinker.kt` — работа с `CameraManager.setTorchMode` без
  запроса разрешения `CAMERA`:
  - держит ограниченный по времени `PARTIAL_WAKE_LOCK`, чтобы спящий процессор
    не заморозил включённый светодиод;
  - отслеживает через `TorchCallback`, не включил ли человек фонарик вручную до
    уведомления, и в `finally` гарантированно возвращает исходное состояние;
  - если камера занята записью видео или звонком, безопасно пропускает серию без
    ошибки;
  - в `AndroidManifest.xml` вспышка и камера помечены `android:required="false"`,
    поэтому APK устанавливается и на планшеты без вспышки, и на ПК-эмулятор
    `x86_64`.
- `ui/screens/settings/FlashlightAlertSettings.kt` — вынесенная карточка раздела
  «Уведомления» (не увеличивает `SettingsScreen.kt`).

## Что проверить на телефонах

1. Телефон А и телефон Б в одной группе; у Б по умолчанию включён «Фонарик при
   SOS из группы». А нажимает красную кнопку SOS → у Б мигает фонарик серией
   `··· −−− ···`, даже если группа у Б без звука.
2. На телефоне Б выключить «Фонарик при SOS из группы» → при новом SOS звук
   тревоги остаётся, а фонарик не мигает.
3. В «Фонарик для сообщений» выбрать по очереди «Только личные чаты», «Только
   группы», «Только каналы» и «Все сообщения» → короткая двойная вспышка
   срабатывает только для выбранного вида переписки и молчит в чатах без звука.
