# APU v11.70.14

Звонки вне общей Wi-Fi: голос теперь идёт через интернет отдельным постоянным каналом.

- Раньше звонок через мобильную сеть почти не соединялся, а если соединялся — разговор рвался: голос шёл тем же путём, что сообщения, с задержкой до нескольких секунд. Теперь на время звонка телефон открывает отдельный постоянный канал через интернет, по которому сразу идут и сигналы (гудки, ответ, отбой), и голос.
- Голос через интернет сжимается вчетверо (в одной Wi-Fi звук остаётся прежним, без сжатия), а воспроизведение идёт с небольшим запасом, чтобы не трещало при рывках сети. На экране звонка в этом режиме подпись «Через интернет — сжатый звук, возможна задержка».
- Если Wi-Fi пропала посреди разговора, звонок не обрывается, а переезжает на интернет-канал.
- Честно: это путь через общедоступные ретрансляторы, они не рассчитаны на голос — задержка и пропадания возможны. Проверьте и напишите, как слышно; следующий шаг для мобильной сети — прямое соединение телефонов.
- Со старыми версиями APU всё работает как раньше: новые возможности включаются только когда обновлены оба телефона.

Обновление получают все: окно с предложением обновиться появится при запуске.
