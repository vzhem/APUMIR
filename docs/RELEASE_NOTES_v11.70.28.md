# APU v11.70.28

Личные файлы передаются быстрее: данные идут напрямую между телефонами, не проходя через сервер.

## Что изменилось

- **Личные файлы летят быстрее.** Фото и файлы в личных чатах теперь передаются напрямую между телефонами, когда они могут соединиться напрямую. Данные больше не проходят через публичный сервер — снят прежний «узкое место» (лимит 10 КБ на сообщение и медленная посылка по частям).
- **Переписка не ждёт файлы.** Пока идёт передача файла, обычные сообщения не тормозят: данные файла уходят отдельным «фоновым» потоком.
- **Старый путь — автоматически.** Если напрямую телефоны не соединяются, файл уходит прежним надёжным путём — передача не прерывается и не зависает.
- **Старые версии работают.** Если собеседник ещё на прежней версии, файл передаётся старым способом; новый быстрый канал включается, когда его понимают обе стороны.
- **Файлы групп не менялись.** Раздача файлов в группах работает так же, как в прошлой версии.

## Совместимость

- База данных не менялась.
- Устанавливается поверх прежней версии — переписка сохраняется.

Обновление получают все: окно с предложением обновиться появится при запуске.
