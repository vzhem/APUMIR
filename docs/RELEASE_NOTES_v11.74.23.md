# APU v11.74.23 — азбука без лимита хранителей; Избранное: файлы и гифки от руки

## 1. Азбука: лимит «5 хранителей» снят

Раньше копия азбуки уходила ровно пяти отобранным телефонам, и в
настройках писалось «N из 5». Теперь:

- копия раздаётся **всем знакомым телефонам** — сколько есть, столько
  и хранит;
- в настройках просто видно число сохранивших:
  **«Копий на других телефонах: N»**.

## 2. Избранное: добавляйте сами

- **Гифки в избранном теперь анимированные** — крутятся, а не стоят
  первым кадром.
- Кнопка **«+»** внизу справа открывает меню:
  - **«Файл с телефона»** — любой файл из памяти телефона ложится в
    избранное;
  - **«Гифка с телефона»** — гифка оседает в библиотеке (и уходит в
    каталог сети) и попадает в избранное;
  - **«Из каталога гифок»** — поиск во внешнем каталоге, скачали —
    в библиотеке и в избранном;
  - **«Свои гифки»** — выбор из уже лежащих в библиотеке телефона;
  - **«Заметка»** — как раньше.
- У добавленных файлов работают «Поделиться» и «Сохранить в телефон».
  При удалении записи своя копия файла стирается, место не тратится.
