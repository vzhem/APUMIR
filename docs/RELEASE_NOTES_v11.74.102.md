# APU v11.74.102 — панель стикеров: пустые плитки оживают; подписи в одну строку

## Что изменилось (раунд 205)

Владелец (скрин панели «Стикеры» в личке с server10): «Есть не
загружаемые стикеры. Также текст в пузырях не умещается» — в
«Недавних» и «Моих» пустые бежевые клетки, а «Эмодзи»/«Стикеры»
переносятся посреди слова.

### Пустые плитки

rowStickers рисовал StickerAnimated(entry.file) безусловно: если файл
стикера на диске отсутствует (чистка хранилища, перенос, сбой),
плитка оставалась ПУСТОЙ. Теперь:
- файла нет → полупрозрачная миниатюра с хранителя (tinyThumbFile)
  или 🧩; значок «⤓» в углу; нажатие докачивает стикер у хранителей
  роя (запрос идёт по записи каталога «Из сети» с настоящими holders -
  requestSwarmSticker); после приезда файл на месте, плитка живая;
- в каталоге «Из сети» стикера нет → значок «×» (докачать неоткуда),
  нажатие неактивно; долгое нажатие в «Моих» по-прежнему удаляет
  запись (уборка битых плиток руками).

### Переносы подписей

SectionPill: подпись раздела maxLines = 1, softWrap = false - «Эмодзи»,
«Гиф», «Стикеры» всегда одной строкой; интервалы чуть поджаты.

НЕ тронуто: ядро, E2E, MQTT, схема Room, механика отправки стикеров.
