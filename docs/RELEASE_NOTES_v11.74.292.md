# APU v11.74.292 — Язык интерфейса: статистика, скорость и статус сервера

Продолжаем перевод интерфейса на выбранный язык.

- Статистика группы: описание каждого дня (число публикаций или сообщений и авторов) выводится на выбранном языке для подсказок и озвучивания экрана.
- Пиры: скорость передачи показывается в единицах выбранного языка (МБ/с, КБ/с, Б/с).
- Настройки: статус сервера до первой проверки выводится на выбранном языке.
- Группа: подпись цитаты ответа для участника без имени переведена.
- Профиль: дата создания резервной копии форматируется по языку телефона.
