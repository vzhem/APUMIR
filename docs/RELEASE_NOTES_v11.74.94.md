# APU v11.74.94 — «Пригласить в APU» на главной + фикс прикрепления APK

## Что изменилось (раунд 199)

Владелец (скрин главной, меню «три точки»: «Избранное», «Подключиться
по ссылке»): «Пригласить в апю нужно добавить на главную страницу в три
точки справа вверху в меню. Из профиля попробовал отправить приглашение

но как файл не прикрепился. Только ссылки прикрепляются».

### Диагноз «файл не прикрепился»

Классическая ловушка Android: Intent.createChooser без clipData НЕ
пробрасывает целевому приложению FLAG_GRANT_READ_URI_PERMISSION на
EXTRA_STREAM - мессенджер получает SecurityException при чтении и
молча показывает один текст; тихий fallback (р197) маскировал отказ.
Рецепт из документации: clipData = ClipData.newRawUri + флаг на сам
send-интент И на chooser.

### Фиксы

1. AppShare.shareApkWithText: clipData + FLAG_GRANT_READ_URI_PERMISSION
   на send и на chooser.
2. AppShare.shareTextWithApk: при неудаче - Toast с главного лупера
   «Файл приложить не вышло - отправлен текст со ссылкой» (р181: Toast
   только с main; р183 - это пользовательский диалог честности, не лог).
3. ChatListScreen: меню «три точки» - новый пункт «Пригласить в APU»
   (PersonAdd): OwnInvite.link/displayName -> ShortShare.shareInvite
   (тот же путь, что из «Контактов»; пустая ссылка - Toast «Личность
   ещё не создана»).

НЕ тронуто: ShortShare, роевые механики, ядро, E2E.
