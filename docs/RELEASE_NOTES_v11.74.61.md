## Что изменилось

архивом»): «нужно чтобы можно было добавлять свои стикеры: сразу
альбом одной темы .zip и по одному .webp и другие форматы».

  после добавления сетка перезагружается (LaunchedEffect(tick)).

    внутри библиотеки), тост «Стикер добавлен в библиотеку»;

    webp/png/jpg/jpeg/gif/bmp -> addBytes(bytes, имя без расш);
    видео-webm пропускается; итог «Добавлено стикеров: N из M»;
    ошибка архива - «Не удалось открыть архив».

  Избранное (local:stk, р163).
