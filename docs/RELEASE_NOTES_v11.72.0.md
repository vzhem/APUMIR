# APU v11.72.0

APU стало ещё «памятливее»: как только телефон сменил сеть, перезагрузился или у него поменялся внешний адрес, APU за секунды (а не за минуту) рассказывает всем вашим контактам и участникам ваших групп, где вас теперь искать. После перезагрузки сообщения и звонки находят вас быстрее — собеседники сразу знают новый адрес.

- Исправлена ошибка: новый адрес собеседника, присланный в presence-сообщении, теперь записывается в адресную книгу и не теряется после перезагрузки.
- Всё остальное — как в v11.71.0.

Обновление получают все: окно с предложением обновиться появится при запуске.
