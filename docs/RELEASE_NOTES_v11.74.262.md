# APU v11.74.262 — Названия аватаров на английском

Названия 50 готовых аватаров (лиса, кит, ракета, гитара и др.) теперь выводятся на выбранном языке. Список вынесен в строковый массив ресурсов, поэтому его можно дополнить переводом без правок кода.
