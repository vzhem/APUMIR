# APU v11.74.143 — синхронизация без лишних действий

## Что изменилось (раунд 246)

### Уже подключённые телефоны синхронизируются сами

Для двух устройств с одним профилем APU держит живое зеркало в фоне: обычные
сообщения, контакты, реакции, медиа и звонки не требуют открывать окно
переноса, вводить пароль копии или нажимать «Забрать».

Чтобы не путать живую синхронизацию с разовой миграцией, пункт настроек теперь
называется **«Перенос профиля на новое устройство»**. Внутри коротко объяснено:
это окно нужно только при первом переносе/восстановлении; на уже настроенных
телефонах зеркало работает само. Перед заменой базы при полном переносе всё
ещё требуется явное подтверждение — тихо стирать локальные данные нельзя.

### Исправлена автоматическая находка копии между телефонами одного профиля

Раньше метка устройства на полке копии была `nodeId` личности. Но у двух
телефонов одного профиля `nodeId` одинаковый: каждый мог принять копию другого
телефона за свою и не предложить её забрать. Теперь используется случайный
128-битный идентификатор установки, который хранится отдельно и не переносится
в резервной копии профиля. Старые метки `nodeId` распознаются для совместимости.

### Ошибка брокера не требует действий человека

Если брокер не прислал ConnAck, приложение продолжает переподключаться само.
Статус в настройках теперь прямо говорит об автоматическом восстановлении;
проверка «Наш сервер» и подключение к брокеру — разные каналы. Отправлять
профиль или менять его пароль из-за краткой сетевой заминки не нужно.

## Ограничение безопасности

Первичная настройка нового телефона всё ещё требует подтверждения применения
полной копии: в ней заменяются локальная база и настройки. После того как оба
устройства уже работают с одной личностью, обычная синхронизация идёт в фоне
без таких подтверждений.

## Проверка

- Unit-тесты идентификатора установки: новый уникальный ID, распознавание
  другого устройства, сохранение совместимости со старыми `nodeId`-метками.
- Полный телефонный проход: см. `docs/MIRROR_SYNC.md` §7, пункты 1–28.
