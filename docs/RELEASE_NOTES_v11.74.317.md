# APU v11.74.317 — Группы: меню и строка ввода

- В группах удержание на стикере или файле открывает меню сообщения.
- У сообщений в группах убраны значки закрепа и «три точки» - пузыри стали шире. Меню по удержанию никуда не делось, закрепить сообщение можно оттуда.
- Голосовое сообщение после записи теперь показывается над полем ввода, а не под ним.
