# Расписание запрета сообщений в группе

Настройки группы → «Расписание запрета сообщений».

- До 32 независимых интервалов; у каждого свои дни начала (Пн–Вс) и время.
  Пересекающиеся запреты объединяются. Можно добавить, изменить и удалить интервал.
- Время в формате ЧЧ:ММ, отдельный часовой пояс IANA с поиском в списке.
- Пн 23:00–08:00 означает ночь с понедельника на вторник. Начало включительно,
  окончание исключительно. Равные начало и окончание отклоняются.
- Обычные участники не отправляют и не редактируют сообщения во всех темах.
  Владелец и администраторы освобождены от ограничения.
- Настройку меняют владелец и администраторы с правом изменения информации.
- Проверка есть в репозитории отправки (включая вложения и пересылку через него),
  а также при обработке отложенных сообщений. UI показывает причину блокировки.
- Таблица groups хранит настройку в quietHours. Миграция 28→29 добавляет поле
  с пустым значением: прежние группы по умолчанию без расписания.
- Отдельные wire-пакеты quiet_hours / quiet_hours_get передают настройки.
  Новичок получает настройку при приёме и дополнительно запрашивает её после
  GroupInfo, чтобы пережить перестановку пакетов между транспортами.

## Совместимость и ограничения

Это клиентская политика, аналогичная существующему медленному режиму, не
централизованный серверный запрет. Участникам нужна версия с поддержкой
расписания. Старые клиенты пропустят незнакомый пакет и не будут блокировать
отправку. Уже отправленные сообщения могут доставляться во время запрета:
входящая история не удаляется по времени её получения. Время берётся с часов
устройства, но преобразуется в общий часовой пояс группы.

## Проверки перед выпуском

JUnit: GroupQuietHoursTest (несколько интервалов, пересечения, границы интервала, переход через полночь/воскресенье,
выбранные дни, DST, валидация, wire). Включён в чистый JVM и Android gates.
В текущем окружении нет Java: Kotlin/Android сборка и тесты не запускались.
SQL миграции проверен на SQLite с сохранением существующей записи.

На двух устройствах проверить:
1. Создать ночное расписание и убедиться, что оно пришло обычному участнику.
2. Граница начала/окончания: кнопка обновляется без повторного входа в чат.
3. Текст, фото, файл, опрос, пересылка и правка сообщения не обходят запрет.
4. Администратор пишет, обычный участник видит объяснение.
5. Отключение расписания, перезапуск, новичок открытой и закрытой группы.
6. Разные часовые пояса устройств при одинаковом времени UTC.
