# APU v11.74.2

Две находки из «жёсткой» мобильной сети, где оператор пускает только белый список хостов.

- **Сообщения теперь отправляются и там.** Раньше в такой сети MQTT-брокеры были недоступны (закрыт порт 1883), и переписка молчала. Теперь, если прямые брокеры не отвечают, сигнальные сообщения идут через наш relay-домен по TLS-443 (WebSecureSocket-мост на Cloudflare), который белый список пропускает. Сквозное шифрование не изменилось: мост видит только зашифрованный трафик.
- **Объявление об обновлении появляется и там.** Проверка и скачивание обновления идут через relay-домен, если GitHub недоступен (это пришло в v11.74.1 на Wi-Fi, теперь работает и на мобильном интернете). Окно «Позже» не будет всплывать заново каждую минуту, а после отказа установке APK доигрывает уже прямой канал.

На обычных Wi-Fi сетях поведение не менялось: прямые брокеры отвечают раньше моста, мост даже не включается.

Обновление получают все: окно с предложением обновиться появится при запуске.
