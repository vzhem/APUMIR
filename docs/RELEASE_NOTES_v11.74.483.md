APU 11.74.483

Лёгкая установка: установочный файл стал в три раза меньше.

- Базовое приложение теперь весит около 74 МБ вместо 233 МБ и ставится заметно быстрее — тяжёлые функции больше не лежат в установочном файле мёртвым грузом.
- Перевод сообщений, распознавание голоса в текст и эффекты лиц для видео и историях вынесены в отдельные пакеты. Они докачиваются по желанию в настройках, раздел «Дополнительные функции» — переключатель включает функцию, пакет скачивается один раз.
- Источник пакетов — в первую очередь официальный сайт apu.clan.su без ограничений; если сайт не отвечает или перегружен, пакет отдадут соседи по рою, у кого он уже скачан. Каждый скачавший раздаёт пакет дальше.
- Целостность каждого пакета проверяется по контрольной сумме SHA-256 до установки.
- Если пакет не скачан, соответствующая функция просто недоступна — приложение работает как обычно и не падает.
