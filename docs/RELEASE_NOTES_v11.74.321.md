# Фотографии в историях

- Выбор фото из галереи и предпросмотр перед публикацией.
- Необязательная подпись к фотографии.
- Просмотр фотографий в историях из профиля и полосы историй.

Истории скрыты из переписки и доступны 24 часа. Для просмотра фото получателю нужна новая версия приложения. Доставка истории требует связи с получателем.
