APU 11.74.469

Обновление снова приходит вовремя и скачивается: исправлены два сбоя, из-за которых оно молчало.

- Приложение больше не пытается скачать установочный файл по устаревшему адресу: если сервис прислал чужой или прежний адрес, берётся проверенный путь к последнему выпуску. Раньше загрузка могла не начаться вовсе, без понятной ошибки.
- Номер последней версии больше не «застревает» на старой: сервис определяет её заново при каждом запросе, даже когда основной источник сведений временно недоступен. Раньше телефон мог неделями видеть версию, которой уже несколько выпусков.
- Проверка обновлений по-прежнему идёт через наш сервис, поэтому работает и в мобильных сетях, где часть адресов закрыта.

Существующие сообщения, файлы и настройки не удаляются.
