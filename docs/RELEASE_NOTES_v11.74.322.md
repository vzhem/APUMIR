# Истории доступны без интернета

- Полученные истории с фотографиями сохраняются на телефоне для офлайн-просмотра.
- Сохранённые истории доступны после перезапуска приложения.
- Истории скрыты из переписки и исчезают по истечении 24 часов.

Без связи доступны только истории, которые телефон уже получил.
