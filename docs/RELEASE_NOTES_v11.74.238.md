# APU v11.74.238 — Ответы, черновики, опросы и модерация на английском

На английском выводятся подписи с именами и числами в ответах на сообщения, черновиках контактов, опросах и окне модерации.

- Подпись «Ответ» с именем автора в полосе ответа.
- Подпись «Черновик» у карточки контакта.
- Название варианта опроса в черновике, с номером.
- Пункты модерации «Удалить всё от», «Заблокировать» и счётчик разрешённых прав.
- Кнопка «Продолжить» с количеством выбранных дополнительно сообщений.
