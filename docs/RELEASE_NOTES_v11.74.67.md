# APU v11.74.67 — анимация стикеров (webm покадрово), панель, кнопки

## Что изменилось

Владелец (скрин панели): «Анимации не работают не в чатах не в выборе. И
нужно когда нажимаешь отправить стикер чтобы окно пропадало после
отправки. Кнопки нужно перенести на верх а то когда много стикеров то
сложно поискать для отправки».

Причина неанимации: vibesticker (инструкция сервиса) в WEBP отдаёт
СТАТИЧНЫЕ 512×512 - анимация только в WEBM. Решение - поддержка webm:

1. StickerLibrary: .zip-импорт принимает webm (хранится как есть);
   mimeFor - EBML-подпись -> video/webm; сниферы isWebmBytes/isWebmFile.
2. НОВЫЙ ui/components/StickerAnimated.kt: gif/webp - Coil (как было),
   webm - покадрово: MediaMetadataRetriever извлекает до 12 кадров
   (≤256px) один раз в фоне (LRU-кэш на 6 стикеров), Compose циклит их
   (90 мс); прозрачный фон восстанавливается ключевым цветом (тёмная
   подложка кадра -> alpha 0).
3. Рисование переведено на StickerAnimated: панель стикеров (ячейки
   библиотеки анимируют!), GroupFileCard (группы/каналы),
   FileTransferBubble (личка), SavedScreen («Избранное»).
4. Гейты превью расширены на стикеры: FileCardState.of,
   FileTransferRouter.previewFileFor (+библиотечный fallback для
   исходящих в личке), тихий фильтр передач в личке, парящий пузырь
   r169 - теперь и для webm; PhotoViewer для webm не открывается.
5. Отправка: stageStickerBytes и личный sendSticker шлют честные
   «Стикер.webm»/video/webm (сниф содержимого); «Избранное» сохраняет
   стикер с типом webm.
6. Панель закрывается после отправки стикера (личка и группы).
7. Кнопки «Добавить стикер из телефона» и «Добавить альбом (.zip)»
   перенесены наверх сетки; индексы секций пересчитаны точно
   (recents=2, my=3+max(recents,1), swarm=my+1+stickers).
