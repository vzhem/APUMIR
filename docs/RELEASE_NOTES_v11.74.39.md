# APU v11.74.39 — служебная плашка «На связи» спрятана

## Что изменилось

Постоянная плашка «APU • На связи - рядом N собеседников» ехала по одному
каналу с уведомлениями о сообщениях (высокий приоритет) и вылезала
заметной карточкой. Теперь у неё отдельный канал минимальной важности:

- нет иконки в статус-баре;
- нет времени «Сейчас»;
- без звука и вибрации;
- в шторке опускается в самый низ, в служебный раздел.

Уведомления о сообщениях - прежний высокий канал: всплывают и звучат,
как были. Звонки - свой канал, заметные.

Честное ограничение: совсем убрать плашку Android не позволяет - это
признак живой фоновой службы, без неё система убивает приём сообщений
в фоне (особенно после раунда 141, где фоновая связь и есть
«аварийный минимум»).

## Технические детали

- `MessengerApplication.kt`: канал `CHANNEL_ID` переименован в
  «Сообщения» (важность HIGH сохранена, бейдж включён); новый канал
  `CHANNEL_SERVICE_ID = apu_service_status` - IMPORTANCE_MIN, без
  бейджа. Важность существующего канала менять нельзя - потому новый.
- `service/CoreServerService.kt`: `buildNotification` - служебный канал,
  `PRIORITY_MIN`, `setShowWhen(false)`.
