# APU v11.70.26

Небольшое исправление: кнопка «Назад» на главном экране больше не закрывает приложение.

## Что изменилось

- **«Назад» на главном экране возвращает на вкладку «Все».** На вкладках «Группы», «Каналы» и «Чаты» жест от правого края или кнопка «Назад» теперь переводят на вкладку «Все», а не закрывают приложение.
- **Приложение закрывается по-старому только с вкладки «Все».** Ещё одно нажатие «Назад» на «Все» выводит из приложения, как в обычных приложениях Android.
- **Раздача файла группы (этап K2 из v11.70.25) не менялась.** Ядро и мост пересобраны при сборке версии; полосы от нескольких участников работают так же, как в прошлой версии.

## Совместимость

- База данных не менялась.
- Устанавливается поверх прежней версии — переписка сохраняется.

Обновление получают все: окно с предложением обновиться появится при запуске.
