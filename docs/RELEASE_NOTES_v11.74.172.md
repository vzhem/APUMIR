# APU v11.74.172

Вкладка «Не прочитано» — все чаты, группы и каналы с новыми сообщениями в одном месте, как в Viber.

- На главном экране появилась вкладка «Не прочитано» сразу после «Все» — там только те чаты, группы и каналы, где есть непрочитанные сообщения.
- У вкладки живой счётчик: показывается количество чатов с непрочитанным (до 99+, дальше «99+»), рядом с названием.
- Как только вы прочитали чат, группу или канал — он автоматически исчезает из «Не прочитано».
- Сортировка как везде: закреплённые сверху, затем по времени последнего сообщения.
- Когда всё прочитано — в пустой вкладке подсказка «Нет непрочитанных».
