# APU v11.74.355 — отложенные сообщения

Выбирайте дату и время показа сообщения с предварительной доставкой, пока есть связь.

- Произвольная дата и время для отложенного текста в личных чатах, группах, темах и каналах.
- Предварительная зашифрованная доставка: сохранённая у получателя копия может появиться в назначенное время без сети.
- Подтверждения сохранения скрытых копий отдельно для каждого получателя.
- Отмена отправляет запрос удаления и повторяет его, если подтверждение не получено.
- Восстановление отложенных заданий и запросов отмены после перезапуска приложения.

**Известное ограничение:** для показа без сети копия должна заранее сохраниться у получателя. Android может задерживать показ. Отмена не гарантирует удаление до показа, если получатель без связи; уже прочитанный текст отозвать невозможно. Проверка на двух телефонах ещё не проведена.
