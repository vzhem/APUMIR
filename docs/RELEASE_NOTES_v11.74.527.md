# v11.74.527 — опрос в личном чате виден в переписке

Собрано из `70f75b1`.

Опрос, отправленный другу, снова появляется в ленте — сразу под вопросом, и у
того, кто его создал, и у собеседника. Раньше вопрос уходил, а карточка с
вариантами не рисовалась никогда.

- Карточка опроса ищется по тому же ключу, по которому её рисует чат, — как у
  опросов в группах.
- Если строку вопроса сохранить не удалось, карточка больше не остаётся
  невидимой: показывается ошибка, а неполный опрос убирается.
- В «Логах» строка `пробуждения=` называет, чего именно не хватает для
  пробуждения: собеседник ещё не присылал эпоху, запись не совпала с
  привязками этой пары, эпоха отозвана или пришла неполной.

**Как проверить:** отправить другу опрос — карточка с вариантами должна быть в
чате сразу под вопросом; после его голоса — обновиться.
