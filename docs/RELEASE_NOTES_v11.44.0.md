APU v11.44.0

Устранена главная причина зависаний: проверка состояния связи больше не задерживает отрисовку экрана.

- Приложение перестаёт замирать с окном «не отвечает»: опрос состояния связи ушёл в фон и больше не повторяется каждые несколько секунд поверх рисования экрана.
- Изображения — свой значок, обои, превью файлов и сохранённых — готовятся в фоне и запоминаются, поэтому экраны открываются без задержки.
- Раздел настроек приведён в порядок: убраны справочные строки без действия, настройка прокси встала рядом с его выключателем.
- У строк настроек появились значки с переливами, как в остальном приложении.

Известное ограничение: голосовые звонки между разными сетями пока нестабильны — это отдельная задача.
