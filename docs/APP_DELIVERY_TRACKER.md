- Уши (5 животных) и носы (5 животных): вырезанные PNG с прозрачным фоном в
  `android-app/app/src/main/res/drawable-nodpi/ar_*.png`. Подключены в `StoryFaceArt.kt`
  (общий код превью и записи), загрузка в `data/story/StoryStickers.kt`. Если картинки нет,
  рисуется старая фигура.

  (ML Kit отдаёт MOUTH_LEFT / MOUTH_RIGHT / MOUTH_BOTTOM, в модели StoryFace их пока нет).
- Сырые картинки с зелёным фоном лежат в `/home/user/ar_raw` (вне репозитория), скрипт вырезания `/home/user/ar_chromakey.py`.
- Не проверено сборкой и на телефоне.

## Порядок проверки (без публикации)

1. Запустить сборку из ветки, это НЕ релиз:
   `gh workflow run build-release.yml --ref arena/27f670ff-apumir`
   Workflow при `workflow_dispatch` собирает APK, запускает unit-тесты и кладёт APK в артефакт.
   Публикация при этом запрещена самим workflow.
   ВНИМАНИЕ (2026-10-17): из песочницы этот запуск даёт HTTP 403 «Resource not accessible by integration».
   Тег для обхода не создавать (тег публикует релиз). Нужен запуск владельцем: GitHub → Actions →
   «Build Release APK» → Run workflow → ветка `arena/27f670ff-apumir`. Попросить владельца так сделать.
2. Дождаться результата: `gh run list --workflow=build-release.yml --limit 3`, затем `gh run view <id> --log-failed`.
3. Если сборка упала, исправить ошибку в ветке и повторить п. 1. Не выпускать релиз с красной сборкой.
4. Если сборка зелёная, проверить на телефоне по чек-листу ниже и записать результат в таблицу выше.

## Чек-лист на телефоне (нужен владелец или тестовый телефон)

- Видеоистории: открыть запись, переключить камеру, включить подсветку, снять 5 секунд.
- AR: выбрать фильтр «уши» / «нос» / «глаза», лицо отслеживается в превью.
- AR в видео: сохранённое видео воспроизводится с фильтром.
- Сердечки: игра выключена, на втором телефоне через сутки или после появления контакта в сети видно счёт.
- Таблица: номера 1–100 видны, прокрутка работает, при месте ниже 100 показана строка «Вы — N место».
