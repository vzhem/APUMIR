# APU v11.74.73 — карточка контакта в приглашении

## Что изменилось

1. Приглашение «поделиться контактом» рисуется КАРТОЧКОЙ прямо в
   сообщении: имя (крупно), @никнейм (если известен), ниже золотой
   пузырь «Добавить контакт» (иконка PersonAdd, shape 14dp, primary).
   Тап - экран добавления с готовым адресом
   (NavGraph -> Screen.AddContact.createRoute(Uri.encode(link)));

   причиной «некликабельности» (URL_REGEX ловил только http/https).
   Работает и у приглашений, пришедших в старых сборках (текст не
   менялся).

   («Contact «X» in APU» + строка apu://|p2pmessenger://);
   MessageBubble.ContactInviteCardView - отрисовка.
3. «Контакты»: убрана дублирующая иконка «поделиться» с карточки
   (onShareClick больше не передаётся); все функции - в меню «⋮».
