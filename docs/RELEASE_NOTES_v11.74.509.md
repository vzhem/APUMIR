Обновление улучшает повторную отправку цитат в личных сообщениях.

- При повторной отправке сообщения приложение дополнительно пытается передать сохранённую цитату.
- Ошибка передачи цитаты не меняет результат отправки самого текста.
- При повторе учитываются адресат и очистка переписки.

**Известные ограничения:** удалённый push пока не подключён; отдельные цитаты могут не доставиться. На некоторых старых парах устройств отправка через другое устройство может не сработать. Выпуск ещё не проверен на физических телефонах.
