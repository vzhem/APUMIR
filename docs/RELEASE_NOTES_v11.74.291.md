# APU v11.74.291 — Язык интерфейса: имена участников, пересылка и настройки адресной книги

Продолжаем перевод интерфейса на выбранный язык.

- Канал: имена авторов без имени в контактах выводятся на выбранном языке.
- Сохранённые гифки: сообщение о перегрузке сервера переведено.
- Настройки: сведения о копии адресной книги (сколько адресов в телефоне, когда была копия на сервере, сколько копий на других телефонах) выводятся на выбранном языке.
- Группа: сообщение о заявке на вход в тему переведено.
