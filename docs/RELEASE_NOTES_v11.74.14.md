# APU v11.74.14 — GIF в темах групп и каналов

## Главное

Под полем ввода появилась кнопка **GIF** — встроенный каталог гифок:

- поиск по слову («котики», «привет»…) и популярные сразу;
- выбрал — гифка уходит в тему и видна всем **живой анимацией**;
- гифка передаётся через наш защищённый файловый рой (как файл),
  небольшие доезжают сами, крупные — по кнопке «Скачать», после загрузки
  тоже анимируют;
- тап по гифке — полный экран, анимация продолжается;
- поиск гифок работает через **наш сервер**: ключ каталога спрятан на
  сервере, приложение само по себе ни к каким внешним каталогам не
  ходит. Пока владелец не задал ключ на сервере, кнопка честно напишет,
  что каталог не настроен;
- можно и просто приложить .gif скрепкой из телефона — всё то же самое.

Старые версии видят гифку как файл «📎 gif_….gif» — совместимо.

## Для владельца (чтобы каталог заработал)

1. Получите бесплатный ключ Tenor: console.cloud.google.com → включить
   «Tenor API» → «Credentials» → «Create credentials» → API key.
2. Сохраните ключ в файл `C:\p2p-relay-deploy\tenor-key.txt` (одной
   строкой) и один раз повторите деплой воркера той же командой
   (deploy.ps1) — скрипт сам подхватит файл.

## Прочее

Без изменений шифрования и сервера сообщений.
