# APU v11.74.283 — Модерация, уведомления и опросы на выбранном языке

Диалоги модерации, отключения уведомлений, выбора темы для пересылки и создания опроса теперь выводят текст на выбранном языке.

- Окно модерации сообщений и участников переведено, включая подписи про канал и группу.
- Статус отключённых уведомлений («Уведомления включены», «Отключены до…») переведён.
- Подсказки про пустые посты и темы при пересылке переведены.
- Ошибки в создании опроса (пустой вопрос, мало вариантов) переведены.
- Подписи «Открыто» и «Ещё закрыто», описание отправки контакта, «Нет сообщений» и «Стикер» переведены.
