# APU v11.74.65 — действия карточки стикера под «тремя точками»

## Что изменилось

Владелец (скрин): «Кнопки "сохранить в папку" "поделиться" и
"в избранное" не помещаются под стикером. Сделай лучше в правом
верхнем углу три точки и заходя на них сделай три горизонтальных
пузыря в нашей цветовой гамме».

1. GroupFileCard (группы и каналы): ряд тесных TextButton под
   картинкой убран; в ПРАВОМ ВЕРХНЕМ углу карточки - круглая кнопка
   «три точки» (полупрозрачная подложка, золотой MoreVert), видна
   только когда есть действия.
2. Тап по точкам - DropdownMenu с тремя ГОРИЗОНТАЛЬНЫМИ ПУЗЫРЯМИ в
   гамме APU (CardActionBubble: primary-фон, onPrimary, clip 18,
   иконка + подпись, как SavedAddBubble р163): «Сохранить в папку»
   (Save), «Поделиться» (Share), «В избранное» (Star); показываются
   только доступные (onSave/onShare/onFavorite).
3. Личка не тронута - там своё меню картинки (раунд 44). Карточки без
   превью (документы) - прежний вид.
