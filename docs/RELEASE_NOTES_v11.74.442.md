# v11.74.442

**Исправление односторонней доставки сообщений и квитанций**

- После успешного открытия зашифрованного сообщения приложение сохраняет проверенную привязку отправителя и может отправить обратный ответ без ожидания отдельного File-HELLO.
- Квитанция доставки сначала отправляется защищённым каналом; если привязка ещё не успела установиться, используется только служебный fallback без текста переписки.
- Исправлена гонка статусов, из-за которой уже подтверждённое сообщение могло снова отображаться как отправленное с одной галочкой и кнопкой «Повторить отправку».
- Диагностика теперь различает неизвестный ID квитанции, строку не с этого телефона и уже завершённое сообщение.
- Существующая проверка подписанных квитанций и строгая защита закреплённого ключа сохранены: автоматически менять уже закреплённый ключ приложение не будет.
