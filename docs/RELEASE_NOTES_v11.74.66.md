# APU v11.74.66 — стикеры парят в чатах без рамок и фонов

## Что изменилось

Владелец (скрин): «Нужно у стикеров убрать квадратный фон… чтобы он был
как будто в чате без лишних рамок и фонов. И нужно чтобы они
анимировали. Чтобы это работало так во всех чатах: личные, избранное,
группы и каналы».

1. GroupFileMarker.isSticker - общий предикат (имя «Стикер…» или
   .webp).
2. GroupFileCard: стикер с копией на телефоне - без подложки,
   скруглений и полей карточки (картинка + «три точки» в углу).
3. GroupChatScreen (группы/каналы-комментарии): пузырь сообщения-стикера
   прозрачный (Card containerColor Transparent, elevation 0) - парит в
   ленте, остаются картинка, имя, время, реакции.
4. FileTransferBubble (личка): стикер - без подложки пузыря и без
   служебной «Получено ✓»; остаются картинка с меню-точками.
5. SavedScreen («Избранное»): сохранённые стикеры - без пузыря
   (ApuBubble transparent) и ЖИВОЙ анимацией (webp через Coil, как
   гифки).
6. Декодер анимированного WebP уже включён (ImageDecoderDecoder,
   API 28+) - анимация едет во всех типах чатов.
