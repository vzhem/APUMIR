# Мои каналы в «Сообществах»

В разделе «Сообщества» отображаются свои каналы и подписки.

- «Мои каналы» доступны отдельно от групп и открытого каталога.
- Поиск работает и по «Моим каналам», без повторных предложений подписаться.
- После подписки открывается лента канала.
