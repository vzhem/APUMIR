# v11.74.436

**Цвет текста сообщений теперь можно настроить отдельно для разных типов переписок.**

- **Четыре режима:** отдельный цвет для личных чатов, групп, каналов и тем.
- **Цвет имени:** выбранный цвет собственного имени передаётся участникам и показывается в контактах, списках и группах.
- **Фильтр чтения:** можно оставить в ленте только сообщения выбранного цвета.
- **Каналы и темы:** цвет сохраняется в постах, комментариях, закреплённых сообщениях и при повторной доставке.
- **Для администраторов:** те же настройки доступны при публикации в управляемых группах и каналах.
- **Совместимость:** старые сообщения и обычная доставка продолжают работать без изменений.
