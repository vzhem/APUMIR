# Многострочный редактор историй

После v11.74.357: код следующей версии, не публикация APK.

- Enter — новая строка (multiline + ImeAction.Default), не отправка/закрытие.
  Клавиатуру можно скрыть отдельной кнопкой в заголовке.
- Редактор и просмотр используют один StoryContentCanvas: логический холст
  360×640, одинаковые поля, фон, шрифты/интерлиньяж и фото ContentScale.Fit.
  Холст уменьшается целиком при клавиатуре/в альбоме, без изменения переносов.
  Типографика художественного холста не зависит от fontScale; элементы управления
  приложения сохраняют системный размер шрифта. Разные системные шрифты/OEM могут
  отличаться между телефонами; это не передача растрового изображения текста.
- Строки переносятся по ширине, явные пустые строки/пробелы сохраняются при
  публикации. Лимит прежний, 200 UTF-16 единиц, CRLF/CR нормализуются в LF;
  ограничение редактора не разрезает surrogate pair emoji.
- Размер шрифта автоматически уменьшается только при переполнении холста
  (не более 8 шагов поиска). Очень большое число переносов делает текст мелким,
  но не прячет остаток за горизонтальной прокруткой. Подпись занимает до 40%
  внутренней высоты, не перекрывается кнопками просмотрщика.
- Протокол историй, шифрование, повторная доставка и ключи не меняются.

Дополнительно по присланному отчёту исправлен порядок redaction: UUID скрывается
до короткого hex-поля, чтобы его первый блок не заменялся отдельно от хвоста.
Синтетическая регрессия проверяет все identity fields и повторную очистку;
исходные логи/идентификаторы телефона в репозиторий не копируются.

Проверки: 5 source-wiring contracts; 3 новых pure JVM StoryPublishTest (всего 10),
новый UUID privacy test. Четыре Android renderer-теста: multiline/IME semantics,
одинаковые переносы при разных размерах и fontScale, подпись фото, 200 символов
с большим числом переносов. Source guards не заменяют компиляцию/renderer.
Device-тесты компилируются в CI, но без телефона/эмулятора здесь не запускаются;
реальная клавиша Enter, курсор/выделение на масштабированном холсте и клавиатура
в портрете/альбоме остаются обязательной проверкой на устройстве.
