# v11.74.473

Однократная очистка лишних контактов и автоматическое восстановление актуальных.

- Убираются накопленные служебные записи контактов; переписка, имена и ключи телефонов сохраняются.
- После обновления телефоны автоматически находят друг друга и обмениваются актуальными контактами без повторного QR-кода.
- Старые записи не возвращаются из сетевых кэшей и зеркальных копий.
- Очистка выполняется один раз при обновлении.

Известное ограничение: если телефон сменил идентификатор и не сохранился в прежнем списке, может потребоваться обычное добавление по QR-коду.
