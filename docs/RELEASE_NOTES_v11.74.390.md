# APU MIR v11.74.390

## Исправление: фон в видеосториях

В прошлом выпуске видеостория с выбранным фоном не сохранялась: после обработки приложение по ошибке удаляло готовый файл и показывало сверху технический путь к нему.

Исправлено: промежуточные файлы чистятся, готовое видео больше не трогается. История с фоном теперь сохраняется как обычная, только с выбранным фоном.

Если проверяли фон в прошлый раз — попробуйте ещё раз: запишите видеосторию с любым фоном из списка, видео должно сохраниться с новым фоном. Заодно проверьте фон в видеозвонке кнопкой «Фон».
