## Границы

Отмена — устойчивый запрос с отдельными подтверждениями, не обещание успешного
удаления у недоступного получателя. Запросы и повтор ACK обновляют relay retention;
маркеры отмены подавляют поздние данные/части/fallback на поддерживающих клиентах.
Очистка не удаляет другие сообщения/комментарии/темы. Старый формат удаления
канального поста не отправляется, поскольку он может стереть чужие комментарии.
Android может задержать показ. Прочтение не блокирует удаление сообщения
из истории; невозможно отменить сам факт прочтения.
Серверное развёртывание в этой сессии не изменялось.
