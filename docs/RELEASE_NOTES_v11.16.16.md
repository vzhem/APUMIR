# APU v11.16.16 — тестовая контрольная версия

Это **предварительный тестовый релиз**, а не объявление полной готовности офлайн-сети.

## Что добавлено

- Автоматический origin relay для сообщения получателю, который сейчас недоступен.
- Ограниченный gossip/summary-обмен между совместимыми телефонами-посредниками.
- TTL 7 дней, максимум 8 переходов, dedup и ограничения очередей/трафика.
- Совместимый relay wire-формат для соседних версий.
- Bounded dual-broker transport и production dedup.
- Честный статус `QUEUED_OFFLINE`, когда немедленная доставка невозможна.

## Что проверено

- Data-preserving установка v11.16.16 на Анну, Женю и Стаса: PASS 3/3.
- Controlled launch/readiness: PASS 3/3; стабильные процессы, оба транспорта READY, без crash/ANR.
- Пользователь вручную наблюдал успешную offline UI-доставку через третий телефон.
- Проверенный APK:
  - имя в релизе: `APU-v11.16.16.apk`;
  - размер: `22,664,712` байт;
  - SHA-256: `446A1EE9254B7F57E037398E81209DB9E60C915CE2E3ADBCFA43A3FC8429DC0D`;
  - Android package пока остаётся `com.vladimir.messenger`;
  - существующая подпись приложения сохранена.

## Важное ограничение

Persistent relay custody M8 ещё не реализована. Сейчас чужая relay-очередь находится в памяти
процесса. Если Android уничтожит процесс APU или телефон будет перезагружен до передачи, посредник
может потерять сохранённое сообщение. Поэтому сценарий «Женя уснул, через сутки проснулся и продолжил»
пока считается best-effort, а не гарантией.

Следующий обязательный этап M8 должен зашифрованно сохранять custody перед сном, восстанавливать её
после process death/reboot, после пробуждения запрашивать новые допустимые relay items, пытаться
передать старые и новые сообщения и снова сохранять всё недоставленное без сброса TTL.

Последующий read-only capture не содержал exact message text/protocol markers, поэтому полная цепочка
конкретного message ID, receipt cleanup и eventual origin `DELIVERED` ещё не доказаны отдельным
инженерным acceptance-тестом.

## Установка

Устанавливать APK поверх существующей APU без удаления приложения и без очистки данных. Перед
установкой отдельно сохранить резервную копию. Проверить SHA-256 APK по значению выше.
