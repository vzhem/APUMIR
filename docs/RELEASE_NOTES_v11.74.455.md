APU 11.74.455

Ключ этого телефона можно вернуть из копии, не теряя переписку.

- В «Резервная копия» появилась кнопка «Вернуть только ключи»: из копии этого же профиля возвращаются только ключи подписи и обмена, а чаты, файлы и настройки остаются на месте. Пригодится, когда приложение пишет «Ключ этого телефона не читается», а копия месячной давности.
- Полное восстановление по-прежнему заменяет профиль — теперь рядом с ним виден и второй, безопасный путь.
- Плашка «телефон молчит» больше не путает две разные поломки: сбой ключа обмена файлами показывается отдельно от нечитаемого ключа личности.
- Восстановление из копии больше не может молча оставить телефон без ключа личности: секреты из копии читаются и проверяются до замены данных, а нечитаемый файл отбивает восстановление и виден в логе.
- Копия принимается только от того же профиля: чужие ключи этому телефону не подставятся.

Существующие сообщения, файлы и настройки не удаляются.
