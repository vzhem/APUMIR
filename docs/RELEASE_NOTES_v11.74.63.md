# APU v11.74.63 — стикер в чатах показывается анимированной картинкой

## Что изменилось

Владелец (скрин группы): «Стикер не показывается в чате. Проверь
личные группы и каналы. Нужно чтобы он показывался анимированной
картинкой».

1. Группы/каналы: визитка стикера отправляется с типом image/webp и
   именем «Стикер.webp» (GroupFileSwarm.stageStickerBytes - байты уже
   на телефоне, без повторного чтения файла).
2. Получатель больше не жмёт «Скачать»: лента сама тихо запрашивает
   файл стикера (маленький - качается мгновенно), и анимация
   появляется сразу.
3. Рисование: FileTransferBubble (личка) и GroupFileCard
   (группы/каналы) крутят webp-стикер через Coil-анимацию - так же,
   как гифки (GroupFileMarker.isAnimatedImage). В ленте группы стикер
   с локальной копией показывается картинкой без файловой карточки.
4. Подписи: «Стикер.webp» на карточке, «🖼 Стикер» в уведомлениях и
   списках (раунд 165).
