# APU v11.74.348 — галочка публикует историю, альбом не прячет кнопки

Синяя галочка на клавиатуре отправляет историю. В горизонтали «Опубликовать» остаётся на экране.

- Галочка на клавиатуре — то же подтверждение, что кнопка «Опубликовать».
- В альбоме кнопки больше не уезжают вниз: короткий ряд фото и отправка всегда видны.
- Пока печатаете, крупные кнопки прячутся, чтобы осталось место для отправки.
- Свайп вниз по снимку по-прежнему опускает клавиатуру.

**Ограничение:** новую версию нужно поставить, чтобы увидеть исправленный редактор истории.

## English

**APU v11.74.348 — keyboard check publishes the story; landscape keeps the buttons**

The blue check on the keyboard sends the story. In landscape, Publish stays on screen.

- The keyboard check is the same confirmation as the Publish button.
- In landscape the buttons no longer slide off the bottom: a short photo row and send stay visible.
- While typing, the large photo buttons hide so there is room to send.
- A swipe down on the picture still dismisses the keyboard.

**Limitation:** install the new version to see the fixed story editor.
