APU 11.74.482

Новый раздел настроек «Дополнительные функции» — подготовка к лёгкой установке.

- В настройках появился раздел «Дополнительные функции»: перевод сообщений, голосовые в текст и эффекты для видео можно будет докачивать отдельно, когда они нужны, а не держать всё в установочном файле.
- Приложение уже умеет получать такие пакеты: в первую очередь — с официального сайта apu.clan.su, а если сайт не отвечает — у соседей по рою, у кого пакет уже скачан. Скачавший телефон сам раздаёт пакет дальше.
- Целостность каждого пакета проверяется по контрольной сумме.
- Сами пакеты и уменьшение установочного файла появятся в ближайших обновлениях — раздел уже готов их принимать.
