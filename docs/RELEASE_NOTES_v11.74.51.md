# APU v11.74.51 — закрытые группы не видны в общем поиске

## Что изменилось

Владелец: «создал закрытую группу, но она появилась у других участников
в поиске» (скрин: «тест группа без тем - Вход по заявке» в разделе
«Открытые группы сети»).

Причины (2 слоя):
1) publishMyDirectory рассылал каталог через getOwnPublishable =
   «свои группы со ссылкой» БЕЗ фильтра isPublic - закрытые публиковались
   наравне с открытыми (needsApproval в пакете ехал, но приёмник его
   не фильтровал);
2) matchDirectory показывал ВСЕ записи каталога (кроме своих) - в т.ч.
   с needsApproval=true.

Фиксы:
- GroupDao.getOwnPublishable: + AND isPublic = 1 (закрытые больше
  не публикуются);
- GroupsViewModel.matchDirectory: + !it.needsApproval (раздел
  «Открытые группы сети» честно открытый: записи «вход по заявке»
  скрыты, включая уже разошедшиеся по сети старые).

## Технические детали

  фильтруем тем, что есть: needsApproval; в текущей практике
  approval <=> закрытая). Ссылки-приглашения и вход по заявке не тронуты.
