# APU v11.70.21

По замечаниям с телефона (15 сентября) и рой, этап 11 — мелкие остатки.

## Что изменилось

- **Видно, в какой теме находишься.** Раньше внутри темы группы наверху крупно стояло название группы, а имя темы — мелким серым рядом с числом участников. Теперь наверху значок и имя темы, а под ними — «Тема · название группы». В канале как было: «Комментарии — пост».
- **Файл можно закрепить.** Сообщение с файлом занимало всю ширину, и кнопка «Закрепить» справа выдавливалась за край экрана. Теперь пузырь уступает место кнопке, а закреп есть ещё и в меню долгого нажатия («Закрепить» / «Открепить»). В закреплённых файл показывается со значком по типу и подписью «📎 имя (размер)».
- **Рой, файлы: «у меня нет».** Если попросили файл у участника, у которого копии уже нет (истекла, удалил, вышел из группы), он сразу отвечает «нет» — и телефон тут же спрашивает следующего, а не ждёт полминуты тишины. Старые версии ответа не знают: с ними работает прежнее ожидание.
- **Вышел из группы — её файлы убраны.** Копии файлов для раздачи и незаконченные запросы этой группы удаляются сразу, а не через неделю. То же при удалении группы владельцем.
- **Настройки → «Место под пересылку»** теперь показывают и объём моих файлов для раздачи в сообществах — раньше эта статья в «Занято сейчас» не считалась.

## Совместимость

- Новый пакет «у меня нет» старые версии молча отбрасывают. Схема базы данных прежняя, личные чаты не менялись.

Обновление получают все: окно с предложением обновиться появится при запуске.
