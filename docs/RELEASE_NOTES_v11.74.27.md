# APU v11.74.27 — «Сообщения сети»; ссылки на гифки в группах и комментариях

## 1. Настройки

Пункт «Сообщения (рой)» теперь называется **«Сообщения сети»**.

## 2. Гифки в группах и комментариях — ссылками, как в личке

- Отправляете гифку в группу или в комментарий канала — в ленту
  попадает **карточка от вашего лица**, а не файл.
- Байты каждый участник **тихо подтягивает** с телефонов-хранителей —
  карточка оживает у всех.
- Хранитель отдаёт молча: **в личные чаты ничего не приходит**.
- «Нажмите Отправить» для гифок больше не нужно: выбрали — карточка
  уже едет.
- Обычные файлы (скрепка) едут как раньше — через скачивание.

## 3. Совместимость ссылок

Ссылки от телефонов с предыдущей версией тоже рисуются карточкой —
пока не все обновились, гифки не теряются.
