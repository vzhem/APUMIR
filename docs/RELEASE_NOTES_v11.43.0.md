APU v11.43.0

Список чатов стал плавнее, а собеседники, чьи имена отличались только заглавной буквой, наконец сводятся в одну запись.

- Значки собеседников готовятся в фоне и запоминаются: список чатов больше не замирает при открытии и прокрутке.
- Записи с одинаковым именем в разном написании объединяются при запуске — переписка при этом переносится в оставшийся чат.
- Поле ввода промокода больше не подсказывает пример кода.

Известное ограничение: голосовые звонки между разными сетями пока нестабильны — это отдельная задача.
