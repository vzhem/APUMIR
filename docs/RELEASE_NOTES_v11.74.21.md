# APU v11.74.21 — избранное для файлов и гифок; свои гифки; «В нашей сети»

## 1. Файлы и гифки — в избранное

- **Личный чат**: долгое нажатие на файл или гифку → «Файл в
  избранное». В избранное кладётся сам файл (ссылка на принятую
  копию), а не пустой текст.
- **Группы, каналы, комментарии**: у карточки принятого файла/гифки
  появилась кнопка «В избранное» — рядом с «Сохранить в папку» и
  «Поделиться».
- Избранное — по-прежнему личное: открывается из списка чатов,
  всё зашифровано, на другие телефоны не расползается.

## 2. Свои гифки

В окне гифок, вкладка «В нашей сети» — новая кнопка **«+ Своя»**:

- выбираете .gif из хранилища телефона (до 30 МБ);
- гифка ложится в библиотеку с превью;
- она автоматически объявляется в каталоге сети — теперь она есть у
  всех ваших телефонов;
- внешний каталог не тратится.

## 3. Переименование

Вкладка «Рой» теперь называется **«В нашей сети»**.
