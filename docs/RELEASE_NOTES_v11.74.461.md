APU 11.74.461

В таблице «Лидеры по сердечкам» у каждого результата теперь есть имя — строки без ника больше нет.

- Раньше результат мог остаться безымянным: например, если в профиле не задано имя. Теперь такой участник показывается именем из вашей адресной книги.
- Если этого человека нет в контактах и он сам не назвался, вместо пустоты показывается его короткое сетевое обозначение — так видно, что это тот же участник, но имени у него нет.
- Приложение больше не отправляет в сеть результаты без имени: свой результат всегда подписывается вашим именем, а если профиль пустой — тем же коротким обозначением.
- Строки «Участник» и «Без имени» из таблицы убраны полностью.

Существующие сообщения, файлы и настройки не удаляются.
