Обновление улучшает работу групп, историй и загрузку новых версий APU.

- Приглашения показывают название, описание и условия вступления; уведомления больше не выводят служебную ссылку.
- В заявках на вступление отображаются аватары участников.
- Исправлена компоновка историй при повороте телефона.
- Добавлено расписание запрета сообщений с несколькими интервалами, днями недели и часовым поясом.
- Исправлены причины блокировки кнопки отправки после сообщения в медленном режиме.
- В настройках обновлений появилась постоянная кнопка проверки и скачивания официальной версии.

Для работы расписания участникам группы необходимо обновить приложение.
