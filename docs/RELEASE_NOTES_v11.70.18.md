# APU v11.70.18

Рой, этап 8: файл для того, кто не в сети, теперь хранят два телефона, а не один — и отдают его вместе.

- Раньше файл для отсутствующего получателя уходил на хранение одному общему контакту; если тот телефон пропадал, файл ждал возвращения отправителя. Теперь отправитель, пока сам в сети, отдаёт копию второму хранителю. У отправителя в пузыре файла: «На хранении у 2 телефонов, получатель заберёт при появлении».
- Когда получатель появляется, он берёт файл сразу у обоих: сам говорит каждому хранителю, какие куски прислать, — они отдают разные части, а не одну и ту же. Большой файл приходит быстрее, и пропажа одного из хранителей не останавливает приём.
- Как только файл собран, оба хранителя освобождают место. Если получатель по старой версии подтвердил только одному, второго отпускает отправитель — копии не висят до срока.
- Всё, что касается доверия, не изменилось: хранители видят только зашифрованные куски, получатель проверяет подпись отправителя, чужие файлы принимаются только от контактов и в пределах «Места под пересылку».
- Со старыми версиями совместимо: они принимают файл от первого хранителя как раньше.

Обновление получают все: окно с предложением обновиться появится при запуске.
