# APU v11.74.18 — свой каталог гифок на телефонах роя

## Главное (идея владельца)

**Внешний каталог ограничен (100 запросов в час), внутренний —
безграничный.** Теперь так и работает:

1. **Скачанные гифки навсегда остаются на телефонах.** Каждая гифка из
   каталога (и каждая принятая по рою) оседает в библиотеке телефона:
   сама гифка + превью + карточка в индексе (до 400 штук, старые
   вытесняются).
2. **Каталог «что у кого лежит» расходится по рою** — служебными
   конвертами, как азбука адресов. Зашифровано (E2E), наружу не видно.
   Обмен происходит при запуске приложения и при открытии окна гифок.
3. **Вкладка «Рой» в окне гифок** — общий каталог всех телефонов:
   «мои» (с превью, отправка мгновенно, без сети) и «у роя» (с меткой
   «у N»). Выбор гифки из роя отправляет просьбу хранителю — телефон
   выбирается по рейтингу онлайна (свежий — первым). Хранитель отвечает
   обычной защищённой передачей файлов, и гифка сразу уезжает в чат.
4. **Внешний Giphy — только для новых гифок**, которых нет ни у кого.
   Скачал один раз — дальше она навсегда в рое, лимит больше не мешает.

## Прочее

- В каталоге роя видно фильтр по названию/метке поиска.
- На старых версиях служебные строки каталога видны как текст — после
  обновления всех телефонов их не будет.
- Без изменений шифрования и сервера.
