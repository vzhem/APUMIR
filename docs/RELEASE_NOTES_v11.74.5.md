# APU v11.74.5

Быстрые ответы после смены сети — «адрес в конверте».

Раньше так бывало: человек сменил сеть (например, с Wi-Fi на мобильный интернет), написал вам — дошло, а ваш ответ к нему ехал долго или не ехал вовсе: приложение пыталось доставить его по старому адресу из памяти.

Теперь каждый, кому прямой путь не вышел, прикладывает к сообщению свой свежий адрес (то самое «пришли адрес в сообщении», только автоматически). Получатель записывает его мгновенно и отвечает напрямую — без ожиданий и поиска.

Обновление получают все: окно с предложением обновиться появится при запуске.
