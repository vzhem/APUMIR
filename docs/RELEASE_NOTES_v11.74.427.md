# v11.74.427

**Счётчик репостов.**

У сообщений и постов появился счётчик пересылок — значок «поделиться» с числом под сообщением:

- **Каналы**: под постом рядом с просмотрами и реакциями видно, сколько раз пост переслали дальше. На больших каналах число сходится через сводки администраторов — как просмотры и реакции.
- **Группы**: под сообщением, рядом с реакциями.
- **Личные чаты**: собеседник видит, сколько раз сообщение ушло дальше, и наоборот.

Считаются именно пересылки внутри APU («Поделиться в APU»): каждая пересылка — отдельное событие, повторы по сети счётчик не накручивают. Счётчик появляется только когда пересылки были, пустой ноль не показывается.
