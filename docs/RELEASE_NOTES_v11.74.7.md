# APU v11.74.7

Наш собственный сервер-брокер: рой больше не зависит от сторонних сервисов.

До сих пор телефоны встречались на публичных брокерах (hivemq, emqx, mosquitto) — это был самый ненадёжный кусок схемы: их никто не контролирует, они бывают перегружены, а соединение с ними могло рваться в самый неподходящий момент.

Теперь весь рой живёт на нашем relay-сервере (тот самый p2p-relay.1985vzhem.workers.dev): он сам принимает подключения телефонов, сам раздаёт сообщения подписчикам и сам помнит объявления о присутствии. Прямое соединение и обходной путь в «жёстких» сетях ведут в один и тот же рой — расщеплений больше не будет по построению.

Если наш сервер временно недоступен, приложение само возвращается на публичных брокеров, как раньше, а через час снова попробует наш.

Обновление получают все: окно с предложением обновиться появится при запуске.
