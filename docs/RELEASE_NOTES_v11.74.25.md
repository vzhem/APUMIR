# APU v11.74.25 — гифки ходят ссылками

## Как теперь работает (ровно как вы описали)

Два абонента обмениваются **только ссылками** на гифку, а байты
подтягиваются на каждый телефон с того, где гифка хранится:

1. Выбираете гифку в едином каталоге (с синей точкой или без) —
   в чате **сразу появляется ваша карточка** (от вашего лица):
   «гифка из нашей сети — загружается…».
2. Хранитель отдаёт байты **тихо** — в его личном чате с вами ничего
   не появляется, переписка чистая.
3. Карточка **оживает** — гифка анимируется, как обычное сообщение.
   В чате её ровно одна.
4. У собеседника то же самое: его телефон сам тихо подтягивает байты
   с хранителей — и карточка оживает у него.

Все три пути отправки гифок в личных чатах теперь ссылки: своя гифка,
гифка сети (синяя точка), свежая из внешнего каталога (скачали один
раз — дальше расходится ссылками).

Превью в списке чатов аккуратное: «🖼 Гифка».

Группы и каналы не менялись (там своя механика раздачи).
