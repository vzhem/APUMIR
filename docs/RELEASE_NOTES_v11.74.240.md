# APU v11.74.240 — Счётчики диагностики и подписи групп на английском

На английском выводятся счётчики в отчёте диагностики, подпись комментариев к теме группы и время ожидания в медленном режиме.

- Количество проверок и строк в карточке отчёта диагностики.
- Подпись «Комментарии» с названием темы.
- Подсказка с оставшимися секундами ожидания в медленном режиме группы.
