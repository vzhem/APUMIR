# APU v11.74.256 — Исправление распознавания стикеров при английском языке

При выбранном английском языке стикеры в чате, группах и «Избранном» могли отображаться как обычные файлы. Теперь распознавание не зависит от языка интерфейса: имена стикеров сохраняются и проверяются как прежде.
