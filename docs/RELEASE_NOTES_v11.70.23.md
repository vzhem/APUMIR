# APU v11.70.23

Первый шаг к «ядру, которое становится крепче с ростом числа людей».

## Что изменилось

- **Настройки → «О приложении» → «Ядро».** Новая строка показывает, какое сетевое ядро собрано внутри приложения: версия, тег сборки и число брокеров. Внешне мелочь, по сути — проверка: эту строку отдаёт само ядро через заново собранный мост между Kotlin и Rust. Раньше мост был «заморожен», и добавить в ядро что-то новое было нельзя. Теперь сборка на GitHub собирает мост сама при каждом выпуске — дорога к ускорению файлов, прямым соединениям и хранению сообщений у соседей открыта. План — `docs/CORE_ROADMAP.md`.

## Совместимость

- Формат сообщений, база данных и все экраны, кроме строки в настройках, не менялись.

Обновление получают все: окно с предложением обновиться появится при запуске.
