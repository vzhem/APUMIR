# APU v11.74.314 — Истории в профиле

Истории теперь не появляются в переписке, а открываются из карточки собеседника.

- Истории скрыты из переписки и из предпросмотра чатов: в списке чатов видно «История».
- Чтобы посмотреть историю, откройте профиль собеседника и нажмите «История». Кнопка появляется, только если у контакта есть активная история.

Известное ограничение: на устройствах со старой версией приложения истории могут временно показываться текстом в переписке. Обновите приложение.
