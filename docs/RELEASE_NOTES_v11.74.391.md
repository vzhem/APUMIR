# APU MIR v11.74.391

## Звонок и фон: три исправления

### Громкая связь — только вручную

При видеозвонке громкая связь больше не включается сама. Разговор начинается в обычном динамике, а громкая включается кнопкой «Динамик», когда она нужна.

### Кнопки звонка стали подписанными

Второй ряд кнопок в звонке раньше состоял из одних значков, и «Показать экран» было не найти. Теперь там пилюли со словами: «Показать экран», «Текст звонка» и «Фон».

### Фон в видеосториях

Если модель вырезания человека ещё скачивалась, фон раньше молча не применялся и видео сохранялось обычным. Теперь приложение дожидается модель с повторами, а если фон всё же не лёг — честно скажет об этом, а не сохранит молча.

Заодно: история с фоном из прошлого выпуска уже сохранялась, но могла остаться без фона — проверьте ещё раз после обновления.
