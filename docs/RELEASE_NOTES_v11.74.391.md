# APU MIR v11.74.391

## Видеозвонок без громкой связи по умолчанию

Раньше при видеозвонке громкая связь включалась сама, сразу. Теперь — нет.

- Видеозвонок начинается как обычный: звук в разговорном динамике.
- Громкая связь включается кнопкой «Динамик» на экране звонка, когда она правда нужна, и той же кнопкой выключается.
- То же при демонстрации экрана и видеозвонке от собеседника: динамик сам не переключается, решает человек.
