# APU v11.74.281 — Поиск эмодзи, время последнего визита и размеры файлов на выбранном языке

Поиск эмодзи понимает английские слова, а время последнего визита, размеры файлов и пояснения в группе выводятся на выбранном языке.

- Поиск эмодзи находит значки по английским названиям (русские слова тоже работают).
- «Был(а) сегодня», «Был(а) вчера», «В сети» и дата последнего визита переведены.
- Единицы размера файла (ГБ, МБ, КБ, Б) переведены.
- Пояснения о медленном режиме и о копии профиля в сети переведены.
