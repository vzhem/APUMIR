APU 11.74.471

Приложение лучше держит связь при смене сети и само выбирает, каким путём доставлять сообщения; добавлена поддержка IPv6.

- Смена сети (Wi-Fi → мобильная, включение VPN, выход из авиарежима) больше не оставляет сообщения «висеть»: соединения поднимаются заново сами, очередь досылается, дублей нет.
- Прямой канал теперь работает и по IPv6, и по IPv4, где бы они ни были доступны: если у собеседника есть IPv6, приложение использует его первым, а без IPv6 всё работает как раньше — по IPv4.
- «Сеть сообщений» в настройках показывает состояние линии словами: по какому стеку идёт прямой канал, виден ли телефон из интернета и нужен ли обходной путь.
- Там же два переключателя для сложных сетей: «Только через relay» (когда прямой обмен запрещён, например в чужом Wi-Fi) и «Экономия трафика» (в мобильной сети не открывать прямой канал без нужды). Оба по умолчанию выключены.
- «Использовать IPv6» — на случай, когда оператор выдал IPv6, но он не работает: приложение будет ходить только по IPv4. По умолчанию включено.
- Передача больших файлов устойчивее на медленных и туннельных каналах: выбран безопасный размер дейтаграмм, передача не рвётся на крупных фрагментах.

Известное ограничение: в сетях, где IPv6 не работает, но объявлен, включённый «Использовать IPv6» может на первых секундах давать задержку — этот переключатель и нужен для таких сетей.

Существующие сообщения, файлы и настройки не удаляются.
