# Иконка приложения APU

Мастер-файл: `apu-final-icon-mesh.png` (1024×1024). Из него собраны все размеры в
`android-app/app/src/main/res/mipmap-*` — руками не правятся, только пересевом из мастера.

## Смысл знака

Месенджер, который держится на рое равных узлов.

- **Внешний контур — облако сообщения** с хвостиком: сразу видно, что это мессенджер.
- **Внутри — ядро и серверы**: золотая гранёная сфера с чипом (то же ядро, что на экране
  перед входом) и четыре серверные стойки.
- **Связи — полная сетка**: каждая стойка соединена с ядром и с каждой другой стойкой.
  Десять связей на пять узлов: ни одного изолированного, ни одного главного — «каждый
  соединён с каждым».
- **Палитра** из дизайн-системы: ночь `#010A16`/`#010B1F`, золото `#E4B45A` → бронза
  `#A9741C`, тёмно-синий металл `#0B1C33`.

## Что лежит в res/

| Файл | Назначение |
|---|---|
| `mipmap-{m,h,xh,xxh,xxxh}dpi/ic_launcher.png` | обычная иконка (Android 7 и ниже, старые лаунчеры) |
| `.../ic_launcher_round.png` | круглая иконка (`android:roundIcon`) |
| `.../ic_launcher_foreground.png` | передний план адаптивной иконки, арт в 66% полотна |
| `.../ic_launcher_background.png` | фон адаптивной иконки, ровная ночь `#010B1F` |
| `.../ic_launcher_monochrome.png` | силуэт для «тематических иконок» Android 13+ |
| `mipmap-anydpi-v26/ic_launcher*.xml` | adaptive icon для Android 8+ |
| `mipmap-anydpi-v33/ic_launcher*.xml` | adaptive icon с `monochrome` для Android 13+ |

`monochrome` вынесен в отдельный каталог `-v33`, а не в `-v26`: тег `<monochrome>` знает только
Android 13+, и в `-v26` он был бы лишним для систем 8–12.

## Честное ограничение

На 1024 px сетка связей читается полностью. В лончере на 48 px остаются узнаваемыми облако и
золотое ядро, а стойки выглядят тёмными плашками — детали полной сетки на таком размере
физически не помещаются. Если понадобится читаемая сетка именно в ленчере, нужен упрощённый
вариант знака (крупные узлы, толстые линии), а не этот.
