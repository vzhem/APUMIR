# Обложка перед входом

Смысл: рой равных, который держится сам. Восемь серверов стоят кругом, в центре —
гранёная золотая сфера с чипом. Каждый сервер соединён и с ядром, и с каждым другим
сервером по кругу и через круг: полная сетка связей, ни главного, ни забытого узла.
Никакой иерархии «центр со спутниками» — именно взаимная связь и есть смысл знака.

Палитра только наша: ночь `#010A16`, золото `#E4B45A` → бронза `#A9741C`, металл
`#0B1C33`.

## Требования контракта (`scripts/ci/check-splash-scene.py`)

- WebP **lossless** (`VP8L`, не `VP8`), иначе арт «плывёт» на градиентах.
- Сторона ≥ 1024 px и строго квадрат.
- Размер файла < 2 МБ.
- В коде арт грузится через `FilterQuality.High`, `ContentScale.Fit`, `inScaled = false`:
  без обрезки и без пересэмплирования под плотность экрана.

Текущий файл: 1024×1024, `VP8L`, 1 004 248 B.

## Когда показывается

Правило — `ui/components/SplashSchedule.kt` (`SplashGate`). Обложка показывается при **запуске
приложения** (как в Telegram), даже если ядро уже поднято; поворот экрана и возврат
из фона её не повторяют. Раньше тёплое ядро отменяло обложку целиком — из-за этого
её перестали видеть на телефонах, где ядро живёт в фоне.

## Ограничение

Арт — плоская картинка 1024×1024 с лёгким параллаксом камеры в `SplashCoreScene`.
На экранах с плотностью выше 3x запас по резкости небольшой: дальше 1024 px на
сторону арт лучше не растягивать, а перерисовывать мастер в большем размере.
