# Инструкции для ИИ-агентов в этом репозитории

1. Перед работой прочитай `docs/APP_DELIVERY_TRACKER.md`. Там список задач, которые должны
   работать в приложении, их статус и порядок проверки.
2. Все изменения делай в ветке, которую назначила сессия. Не создавай и не переключай ветки самостоятельно.
3. После каждого изменения обнови статусы в `docs/APP_DELIVERY_TRACKER.md`.
4. Не объявляй задачу готовой, пока сборка из ветки не зелёная (`gh workflow run build-release.yml --ref <ветка>`).
   Сборка через `workflow_dispatch` не публикует релиз.
5. Не публикуй релиз, тег или PR без явного разрешения владельца и показа точного публичного текста
   (`docs/RELEASE_PUBLICATION_POLICY.md`).
6. Не удаляй ветки на GitHub без явного разрешения владельца.
7. Не коммить секреты, ключи, токены и приватные данные.
