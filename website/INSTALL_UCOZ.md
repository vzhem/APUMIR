# Установка одностраничной страницы APU в uCoz

## Перед изменениями — обязательно

1. В панели откройте **Безопасность → Бэкап файлов и базы данных** и создайте резервную копию.
2. Там же выберите **Бэкап шаблонов**.
3. Ничего не удаляйте из модулей и базы до проверки новой главной страницы. Сниппет визуально закрывает старый шаблон на главной, поэтому для первого этапа удалять содержимое сайта не нужно.

## Вставка страницы

1. Откройте **Сайт → Редактор страниц**.
2. Выберите главную страницу сайта.
3. Переключите редактор в режим **HTML / Источник кода**.
4. Замените содержимое главной страницы полным содержимым файла `ucoz-landing.html` и сохраните.
5. Загрузите файл `website/latest.json` в каталог `/downloads` на uCoz с именем `latest.json`.
6. Откройте `https://apu.clan.su/` в приватном окне и проверьте мобильную ширину, подпись версии и скачивание APK.

Это HTML-фрагмент для содержимого страницы, не файл для загрузки в каталог APK. Если uCoz удалит `<style>` или `<script>` при сохранении, не пытайтесь удалять шаблон вслепую: пришлите снимок редактора, и код нужно будет вставить через редактор дизайна.

## APK на uCoz и версия sidecar

По последнему скриншоту файлового менеджера uCoz занято **5.12 из 440.27 МБ**,
то есть свободно примерно **435.15 МБ**. Последний публичный stable-релиз на
2026-11-02 — `v11.74.478`, **233,417,551 байт** (около 222.6 МиБ); SHA-256:
`56ded387d2a585d967ba6b38a458cfd89a1778f381df0e2d8dcf279304d5e1bd`. Значения для
sidecar подготовлены локально; агент не менял и не перепроверял live uCoz. Последняя
подтверждённая владельцем загрузка относилась к предыдущему релизу `v11.74.477`.
Одна копия помещается в общую квоту; оставляйте только одну актуальную версию.

## Результат проверки FTP и лимитов

Первый FTP-запрос целиком был отклонён ответом **552 Quota exceeded**: максимум
**204800 KB** (200 МиБ) на один файл. После нескольких частичных передач с
`REST`/докачкой FileZilla показывала `/downloads/app-release.apk` размером
**233,417,551 байт**. Для предыдущего релиза `v11.74.477` владелец подтвердил,
что публичный URL `https://apu.clan.su/downloads/app-release.apk` скачивает файл
с SHA-256 `8d81ddc7646b81131bba6072182eb62f6977643aa3008e22d6e7e995798f9706`.
Это историческая проверка старой копии; загрузка нового APK `v11.74.478` и live-сайт
после её публикации агентом не проверялись и не менялись.

Локальный `ucoz-landing.html` содержит обе кнопки и автоматический выбор источника.
Без JavaScript, при ошибке сети, при отсутствии `latest.json`, а также если его
версия или SHA-256 не совпадают с последним релизом, кнопки остаются на Worker
`/update/apk`. На проверенной текущей версии кнопки переключаются на
`https://apu.clan.su/downloads/app-release.apk`. Версия релиза и digest берутся у
Worker `/update/latest`; sidecar `latest.json` сообщает, какая версия лежит именно
на uCoz. GitHub-ссылок на странице нет. Live-страницу должен сохранить владелец.

Примечание: исходник Worker в `tools/worker/p2p_relay_worker.js` дополнен выдачей
SHA-256 и признаком устаревшего кэша, но сам live Worker агентом не развёртывался.
До его обновления приложение/страница сравнивают версию; проверка digest работает,
когда endpoint его отдаёт (либо когда приложение получило digest напрямую от GitHub).

### Как обновлять APK в дальнейшем

1. Загрузите новую `app-release.apk` в `/downloads` и убедитесь, что ссылка скачивает её.
2. Только после загрузки APK обновите `latest.json`: поле `version` — тег нового
   релиза, `sha256` — официальный SHA-256 именно этого APK.
3. Загрузите `latest.json` в `/downloads/latest.json` и проверьте его по публичному
   адресу. Если sidecar не обновить или хэш не совпадёт, приложение и кнопки
   страницы безопасно останутся на существующем Worker/GitHub-механизме, а не
   выберут старую копию uCoz.

Для публичного stable-релиза `v11.74.478` подготовлены значения в
`website/latest.json`: SHA-256
`56ded387d2a585d967ba6b38a458cfd89a1778f381df0e2d8dcf279304d5e1bd`. Это файл для
ручной загрузки владельцем, не обновление live-сайта. Загружайте sidecar только после
того, как APK `v11.74.478` вручную заменён в `/downloads` и его контрольная сумма
проверена.

Лимит uCoz в **204800 KB на файл** всё ещё действует. Не автоматизируйте REST-
докачку для обхода ограничения без разрешения uCoz. При свободных ~435 МБ файл
**2 ГБ** не поместится даже частями. Для будущего автоматического размещения на
uCoz потребуется тариф с допустимым размером файла и общей квотой. Внешний
`dfiles.com` принимает большие файлы, но ссылка будет не на `apu.clan.su`; либо
оставьте на live-странице прежнюю кнопку Worker до обновления ссылок.

FileZilla сообщил, что сервер **не поддерживает FTP через TLS**; пароль FTP мог
передаваться незашифрованным. Если он совпадает с паролем другого сервиса, смените
его; используйте отдельный уникальный пароль.
