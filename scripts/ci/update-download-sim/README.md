# Проверка выбора источников обновления без Android

Этот небольшой симулятор компилирует настоящий `OfficialUpdateDownloads.kt` с
поддельными DownloadManager, SharedPreferences и PackageManager. Он проверяет
последовательное переключение, ошибки устройства, проверку файла, конкурирующие
события, отмену, восстановление после прерванного переключения и выбор обновлённой
версии вместо совпавших между собой старой карточки и старого сайта. Он запускается
в конце `scripts/ci/check-chat-history.sh` в отдельном classpath: заглушки
никогда не включаются в приложение.

Симулятор не проверяет настоящий Android DownloadManager, WorkManager,
системные уведомления, реальные сетевые серверы или установку на телефон.
