# Проверка актуальности перед скачиванием

Скрипт `check-update-check-sim.sh` компилирует настоящий `UpdateChecker`,
`UpdateSiteMirror` и `OfficialUpdateDownloads` в отдельной JVM с поддельными
Android, HTTPS и управляемыми JSON-fixtures. Сценарии проходят через реальный
`downloadApk`: старые карточки с обоими вариантами флага, совпадающая старая
копия сайта, версия в запасном URL, устаревший кеш relay (поле и заголовок
старого Worker), рабочий свежий relay, недоступность и регресс версии. Каждый
сетевой запрос проверяет обход кеша. Скрипт запускается из
`check-chat-history.sh`; заглушки не включаются в приложение.

Это не реальный парсер JSON, Android DownloadManager, работающий сайт, Worker,
WorkManager, физическое устройство или установка APK.
